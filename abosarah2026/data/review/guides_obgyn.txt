== Antenatal care & screening
@ المنطق: الحامل الطبيعية جسمها **يتغير** (دم أكثر، كلى تصفي أسرع، سكر يرتفع)، فلا تخافين من أرقام تبان غريبة. والسؤال غالبًا: "وش الفحص المناسب بهذا الأسبوع؟" أو "الأم {Rh−}، وش نسوي؟".
@@ دوري في السؤال على: كم أسبوع · {Rh−} · {anti-D titre} · عمر الأم · {nuchal} · دواء · غثيان شديد
# 1 تغيرات الحمل الطبيعية
> الحمل يزيد **كمية الدم** حوالي 50%، بس البلازما تزيد أكثر من الكريات ← {Hb} ينزل شوي ({physiological anemia}). والكلى يجيها دم أكثر فتصفي أسرع ← {creatinine} **ينزل**. والقلب يدق أسرع شوي، والضغط **ينزل** بالنص الأول.
%% Primigravida 12 weeks, renal tests requested. Most expected finding? → A fall in serum creatinine ✔ || الكلى تصفي أسرع بالحمل، فالـ{creatinine} ينزل. لو طلع "طبيعي للمرأة العادية" فهذا عالي عليها.
| {Normal in pregnancy} | {Abnormal} |
| {Hb} ينزل شوي · {creatinine} ينزل · {ALP} يرتفع (من المشيمة) · ضغط ينزل بالنص الأول | ضغط {≥ 140/90} · بروتين بالبول · {creatinine} طبيعي للمرأة العادية |
# 2 الـ{Rh}
> لو الأم {Rh−} والطفل {Rh+}، ودم الطفل دخل لها (ولادة، نزيف، إجهاض)، جسمها يصنع أجسام {anti-D}. بالحمل الجاي هذي الأجسام تعدي وتكسر كريات الطفل ← أنيميا عند الجنين.
| {Situation} | {Answer} |
| {Rh−} وما عندها أجسام | {anti-D} على 28 أسبوع + بعد الولادة لو الطفل {Rh+} + بعد أي نزيف |
| عندها أجسام و{titre} يرتفع | [ok:{MCA Doppler}] (يقيس أنيميا الجنين بدون إبر) |
!why ليش {MCA Doppler}؟: الجنين الأنيمي دمه خفيف فيجري أسرع بشريان المخ. فالسرعة العالية = أنيميا ← وقتها نفكر بنقل دم للجنين.
# 3 الفحوصات والأدوية
| {Situation} | {Answer} |
| {cystic hygroma} أو {nuchal} عالي على 11–13 أسبوع | {CVS} (تشخيص بدري) |
| بعد 15 أسبوع ونبي تشخيص | {amniocentesis} |
| غثيان شديد + نزل وزنها + {ketones} | {hyperemesis} ← سوائل + {antiemetic} |
| {folic acid} | قبل الحمل بـ3 شهور · جرعة عالية لو صرع أو طفل قبل {NTD} أو سكري |
!warn انتبهي: [no:{MMR}] و{varicella} ممنوعة بالحمل (حية) ← بعد الولادة. {flu} و{Tdap} عادي.
^ ① كم أسبوع؟ ② الرقم طبيعي للحامل؟ ③ {Rh−}؟ ← عندها أجسام؟ لا = {anti-D} · إيه = {MCA Doppler}
== Early pregnancy & bleeding
@ المنطق: نزيف بالحمل: اسألي **كم أسبوع؟** قبل 20 = إجهاض أو {ectopic}. بعد 20 = {previa} أو {abruption}. وأول خطوة دايم: **هي مستقرة؟**
@@ دوري في السؤال على: كم أسبوع · {os} مفتوح ولا مسكر · {US} فيه كيس؟ · {beta-hCG} · ألم ولا بدون ألم · شد بالبطن
# 1 الإجهاض: الـ{os} يحدد
> الإجهاض كله يدور على سؤالين: **عنق الرحم ({os}) مفتوح ولا مسكر؟** و**طلع شي ولا لا؟**
| {Type} | {os} | {US} | {Answer} |
| {Threatened} | مسكر | جنين حي | طمني (غالبًا يكمل) |
| {Inevitable} | مفتوح | لسا داخل | بيطلع ← {evacuation} أو انتظري |
| {Incomplete} | مفتوح | بقايا | {evacuation} أو {misoprostol} |
| {Complete} | مسكر | فاضي | طمني |
| {Missed} | مسكر | جنين بدون نبض | {misoprostol} أو {evacuation} أو انتظري |
%% 9 weeks, very mild pain, brown clots, cervix closed, US: 5-week fetus no heartbeat. Management? → Conservative ✔ || {missed} + هي مستقرة وألمها خفيف ← ممكن ننتظر يطلع لحاله.
# 2 الـ{Ectopic}
> الحمل انزرع بالأنبوب. الأنبوب ضيق، فيكبر لين **ينفجر** ← نزيف داخلي. فكري فيه لما: حمل موجب + ألم بجهة + **الرحم فاضي** بالـ{US}.
| {Situation} | {Answer} |
| مستقرة + صغير + {hCG} واطي + ما فيه نبض | {methotrexate} |
| كبير أو نبض أو ألم شديد | {laparoscopy} ({salpingectomy}) |
| مو مستقرة | [no:عملية فورًا] |
!why ليش {hCG} مهم؟: لو {hCG} فوق 1500–2000 والرحم فاضي، المفروض كنا شفنا الحمل داخل الرحم ← فهو برا = {ectopic}.
# 3 النزيف بعد 20 أسبوع
| | {Placenta previa} | {Abruption} |
| الألم | [ok:بدون ألم] | [no:مع ألم] ورحم قاسي |
| الدم | أحمر فاتح | ممكن قليل والنزيف داخلي |
| أول شي | {US} لمكان المشيمة | استقرار الأم + {CTG} |
!warn انتبهي: نزيف بعد 20 أسبوع ← [no:لا تفحصين بإصبعك] لين تتأكدين من مكان المشيمة بالـ{US}. ونزيف شديد + {DIC} = {abruption}.
^ ① كم أسبوع؟ ② مستقرة؟ ③ قبل 20: {os} + {US} · بعد 20: ألم ولا بدون ألم؟
== Medical problems in pregnancy
@ المنطق: الحامل مريضة بنفس أمراض الناس، بس **الدواء يتغير** لأن بعضها يضر الجنين. والقاعدة: صحة الأم أول، وعلاج الأم غالبًا يحمي الجنين.
@@ دوري في السؤال على: ضغط {≥ 140/90} · بروتين · صداع وزغللة · تشنج · {OGTT} · رجل منتفخة · حكة
# 1 الضغط و{Preeclampsia}
> بعد 20 أسبوع، لو المشيمة ما انزرعت زين، تطلع مواد تضرب العروق ← ضغط + بروتين = {preeclampsia}. وإذا صار **تشنج** = {eclampsia}.
| {Situation} | {Answer} |
| ضغط بعد 20 أسبوع بدون بروتين | {gestational hypertension} |
| ضغط + بروتين (أو صداع، زغللة، كبد) | {preeclampsia} |
| ضغط عالي جدًا (160/110) | {labetalol} · {hydralazine} · {nifedipine} |
| تشنج | {airway} أول ← [ok:{magnesium sulfate}] |
| العلاج النهائي | الولادة |
!why ليش {magnesium} مو أدوية الصرع؟: لأنه يمنع التشنج بالـ{eclampsia} أحسن منها كلها. وعلامة إنه زايد: {reflexes} تختفي ثم تنفس يبطئ ← {calcium gluconate}.
%% Pregnant woman with tonic-clonic seizure. Initial step? → Open and maintain airway ✔ || أي تشنج: الـ{ABC} قبل أي دواء.
# 2 السكر بالحمل
> هرمونات المشيمة تقاوم الـ{insulin}، فبعض الحوامل يرتفع سكرهن = {GDM}. نفحصه بـ{OGTT} على 24–28 أسبوع.
| {Situation} | {Answer} |
| {GDM} | أكل ورياضة ← ما كفى ← [ok:{insulin}] (أو {metformin}) |
| خطره على الطفل | كبير الحجم ({macrosomia}) · سكر واطي بعد الولادة |
| بعد الولادة | {OGTT} بعد 6–12 أسبوع |
# 3 أشياء ثانية
| {Situation} | {Answer} |
| رجل منتفخة أو ضيق | {duplex US} ← {LMWH} (مو {warfarin}) |
| حكة باليدين والرجلين آخر الحمل + {bile acids} | {cholestasis} ← {ursodeoxycholic acid} |
| بكتيريا بالبول بدون أعراض | [ok:عالجيها] (بالحمل تطلع للكلى) |
| فقر دم {MCV} كبير | {folate} |
!warn انتبهي: [no:لا {warfarin}] ولا {ACE-I} ولا {statins} بالحمل.
^ ① ضغط بعد 20؟ ← بروتين؟ ← {preeclampsia} ② تشنج؟ ← {airway} ← {magnesium} ③ سكر؟ ← {insulin} ④ جلطة؟ ← {LMWH}
== Labor & delivery
@ المنطق: الولادة ثلاث أسئلة: **هل هي بولادة فعلًا؟** · **هل تتقدم زين؟** · **هل الجنين بخير ({CTG})؟** ولما يطلع فيه مشكلة، الجواب يا ننتظر يا نسرع يا قيصرية.
@@ دوري في السؤال على: {cm} كم · {station} · كم ساعة · {epidural} · {CTG} · الماي نازل · {breech} · كم أسبوع
# 1 الولادة تتقدم؟
> الطلق الحقيقي = انقباضات **منتظمة تفتح** عنق الرحم. أول ({latent}) لين 6 سم يكون بطيء، بعدها ({active}) المفروض حوالي 1 سم بالساعة. المرحلة الثانية = من الفتح الكامل لين يطلع الطفل.
| {Situation} | {Answer} |
| انقباضات ورحم ما يفتح | {false labor} ← طمني |
| {active} وما تقدمت + الماي ما نزل | [ok:{amniotomy}] |
| ما تقدمت + انقباضات ضعيفة | {oxytocin} |
| فتح كامل + راس الطفل واضح + مع {epidural} | ممكن تنتظر شوي (عندها وقت أطول) |
| ما تقدم + راس مو نازل أو {CTG} سيئ | {C-section} |
%% Primigravida, fully dilated for 2 hours with epidural, fetal scalp at introitus, CTG fine. Next? → Wait 1 more hour ✔ || مع الـ{epidural} المرحلة الثانية مسموح تطول (3 ساعات للبكر)، والطفل بخير وقريب ← ننتظر.
# 2 الماي نزل ({PROM}) والخديج
> لو الماي نزل قبل الطلق: **كم أسبوع؟** لو مكتملة (37+) ← نولّدها ({induction}) لأن الانتظار يجيب التهاب. لو خديج ← نحاول نأخر عشان رئة الطفل.
| {Situation} | {Answer} |
| 37+ أسبوع + الماي نزل | [ok:{induction of labor}] |
| أقل من 34 + الماي نزل | {steroids} (رئة الطفل) + {antibiotics} ({erythromycin}) |
| طلق قبل موعده | {steroids} + {tocolysis} ({nifedipine}) |
| حرارة + ماي بريحة + نبض الجنين سريع | {chorioamnionitis} ← {antibiotics} + ولادة |
!why ليش {steroids} قبل 34؟: لأنها تسرع نضج رئة الجنين وتنتج {surfactant}، فيقل عنده {RDS}.
# 3 الـ{CTG}
> نبض الجنين الطبيعي 110–160 مع تذبذب ({variability}). أهم شي تفرقين بين أنواع النزول ({decelerations}):
| {Type} | ليش يصير | {Answer} |
| {Early} | راسه ينضغط مع الانقباض | طبيعي |
| {Variable} | الحبل السري ينضغط | غيري وضعيتها + سوائل |
| {Late} | المشيمة ما توصل أكسجين | [no:خطر] ← وقفي {oxytocin} + {O2} ← ولادة سريعة |
# 4 الوضعيات والطوارئ
| {Situation} | {Answer} |
| {breech} على 36–37 أسبوع | {ECV} (ممنوع لو الماي قليل أو مشيمة نازلة) |
| الحبل طلع قبل الطفل | ارفعي الراس عن الحبل ← قيصرية فورًا |
| راس طلع والكتف علق | {McRoberts} + ضغط فوق العانة |
^ ① في ولادة؟ (يفتح؟) ② تتقدم؟ ← {amniotomy} أو {oxytocin} ③ {CTG}؟ ← {late} = خطر ④ الماي نزل؟ ← كم أسبوع؟
== Postpartum
@ المنطق: بعد الولادة أكبر خطر **النزيف** ({PPH})، وأشهر سببه إن الرحم **ما انقبض** ({atony}). بعدها التهاب، ثم مزاج.
@@ دوري في السؤال على: كمية الدم · الرحم طري · المشيمة كاملة؟ · حرارة · كم يوم بعد الولادة · رضاعة · مزاج
# 1 النزيف بعد الولادة
> بعد ما تطلع المشيمة، الرحم لازم **ينقبض** عشان يعصر العروق ويوقف النزيف. لو بقى رخو ← ينزف. عشان كذا أول شي **تدليك الرحم** + {oxytocin}.
| السبب ({4 Ts}) | {Answer} |
| {Tone}: رحم رخو (الأشهر) | تدليك + {oxytocin} ← {carboprost} ([no:مو للربو]) ← {misoprostol} ← عملية |
| {Tissue}: بقايا مشيمة | طلعيها |
| {Trauma}: تمزق | خياطة |
| {Thrombin}: دم ما يتجلط ({ITP}، {DIC}) | عوضي (مثلًا {platelets}) |
%% Known ITP, postpartum hemorrhage. Next step? → Platelets ✔ || سببها هنا {thrombin}: الصفائح أصلًا قليلة، فعوضيها.
# 2 الحرارة بعد الولادة
| {Situation} | {Answer} |
| حرارة + إفرازات بريحة + رحم يعور | {endometritis} ← [ok:{IV antibiotics}] |
| حرارة + جرح القيصرية أحمر وفيه صديد | افتحي الجرح ونظفيه + {culture} |
| ثدي أحمر ويعور + حرارة | {mastitis} ← {antibiotic} + [ok:كملي الرضاعة] |
# 3 المزاج ومنع الحمل
| {Situation} | {Answer} |
| بكاء وتقلب أول أسبوعين بس | {baby blues} ← طمني |
| حزن أكثر من أسبوعين | {postpartum depression} ← علاج |
| تهلوس أو تبي تأذي الطفل | {psychosis} ← طوارئ |
| ما ترضع وتبي حبوب مركبة | بعد 3 أسابيع (خطر الجلطة قبلها) |
^ ① نزيف؟ ← الرحم رخو؟ ← تدليك + {oxytocin} ② حرارة؟ ← الرحم ولا الجرح ولا الثدي ③ مزاج؟ ← كم صار له؟
== Menstrual disorders & amenorrhea
@ المنطق: الدورة تحتاج سلسلة شغالة: **المخ ← المبايض ← الرحم ← مخرج مفتوح**. أي حلقة تخرب تقطع الدورة. وأول فحص دايم: [no:{pregnancy test}].
@@ دوري في السؤال على: حمل؟ · عمرها · صفات أنثوية موجودة؟ · ألم دوري · شعر زايد · وزن · {prolactin}
# 1 انقطاع الدورة
> **{Primary}** = ما جتها أبدًا (لين 15 سنة). **{Secondary}** = كانت تجي ووقفت 3 شهور. وأول شي حمل.
| الصورة | السبب | {Answer} |
| بلوغ طبيعي + ألم كل شهر + انتفاخ | المخرج مسدود ({imperforate hymen}) | فتح |
| قصيرة + ما فيه بلوغ | {Turner} | {karyotype} |
| دورة غير منتظمة + شعر + حبوب + وزن | {PCOS} | {OCP} + وزن · تبي حمل ← {letrozole} |
| حليب من الثدي | {prolactin} عالي | {MRI} + {cabergoline} |
| رياضة أو نحافة شديدة | المخ وقف ({hypothalamic}) | وزن وأكل |
%% 16-year-old, primary amenorrhea, cyclical pain, imperforate hymen, cruciate incision done. Next? → Topical estrogen cream for 2 weeks ✔ || بعد الفتح نعطي {estrogen} موضعي يساعد الجرح يلتئم وما يلزق.
# 2 النزيف الكثير
> اسألي **عمرها**: صغيرة ← غالبًا هرمونات. فوق 45 أو بعد سن اليأس ← [no:لازم {endometrial biopsy}] لأن السرطان وارد.
| {Situation} | {Answer} |
| نزيف كثير ورحم كبير وكتل | {fibroids} ← {US} |
| رحم كبير طري + دورة تعور | {adenomyosis} |
| أي نزيف بعد سن اليأس | {US} لسمك البطانة ← {biopsy} |
| نزيف كثير وتبي علاج بدون هرمون | {tranexamic acid} |
# 3 ألم الدورة
| {Situation} | {Answer} |
| ألم أول يومين وبنت صغيرة | {NSAIDs} أو [ok:{OCP}] |
| ألم يزيد سنة عن سنة + ألم جماع + تأخر حمل | {endometriosis} ← {laparoscopy} |
^ ① حمل؟ ② {primary} ولا {secondary}؟ ③ وين الحلقة الخربانة؟ مخ · مبيض · رحم · مخرج ④ كبيرة وتنزف؟ ← {biopsy}
== Infertility, contraception & menopause
@ المنطق: تأخر حمل = سنة بدون حمل (6 شهور لو فوق 35) ← افحصي **الزوجين**. منع الحمل: اختاري حسب **وش ممنوع عليها**. سن اليأس: الأعراض تتعالج بالهرمون إذا ما فيه مانع.
@@ دوري في السؤال على: كم صار لهم · عمرها · جلطة قبل · صداع {aura} · مدخنة فوق 35 · رضاعة · أعراض سن اليأس
# 1 تأخر الحمل
> الحمل يحتاج: **بويضة** (تبيض؟) + **أنبوب مفتوح** + **حيوانات منوية**. فنفحص الثلاثة، ومن الزوجين.
| {Situation} | {Answer} |
| سنة بدون حمل | [ok:فحص الزوج والزوجة] |
| تبيض؟ | {progesterone} يوم 21 |
| الأنابيب مفتوحة؟ | {HSG} |
| الزوج | {semen analysis} (أسهل فحص) |
| {PCOS} ما تبيض | {letrozole} أو {clomiphene} |
# 2 منع الحمل
> الحبوب المركبة فيها {estrogen}، وهذا **يجلط**. عشان كذا ممنوعة على: جلطة قبل · صداع مع {aura} · مدخنة فوق 35 · أول 3 أسابيع بعد الولادة.
| {Situation} | {Answer} |
| جلطة قبل | [ok:{IUD}] (النحاس ما فيه هرمون) أو حبوب بروجستيرون بس |
| ترضع | بروجستيرون بس أو {IUD} |
| بعد جماع بدون حماية | حبة طوارئ أو {copper IUD} (الأقوى، لين 5 أيام) |
%% Woman with DVT in her last pregnancy wants contraception. Best? → IUD ✔ || {estrogen} يجلط، فلازم شي بدون {estrogen}.
# 3 سن اليأس
| {Situation} | {Answer} |
| هبات حرارة + عرق + نوم | {HRT} (لو عندها رحم: {estrogen} + {progesterone}) |
| ما عندها رحم | {estrogen} بس |
| ممنوع {HRT} | سرطان ثدي · جلطة · نزيف مو معروف |
!why ليش {progesterone} مع {estrogen} لو عندها رحم؟: لأن {estrogen} لحاله يكبر بطانة الرحم ← ممكن تصير سرطان. الـ{progesterone} يحميها.
^ ① تأخر؟ ← بويضة + أنبوب + زوج ② منع حمل؟ ← وش ممنوع عليها ({estrogen})؟ ③ سن اليأس؟ ← عندها رحم؟
== Gyn infections & pelvic pain
@ المنطق: الإفرازات: **لونها وريحتها** تحدد السبب. ألم الحوض: **حامل؟** (ممكن {ectopic}) ← بعدين حرارة؟ ({PID}) ← فجأة؟ ({torsion}).
@@ دوري في السؤال على: لون الإفرازات · ريحة سمك · حكة · حرارة · ألم فجأة · {cervical motion tenderness}
# 1 الإفرازات
| {Type} | الإفرازات | {Answer} |
| {Candida} | بيضا زي الجبن + حكة | {fluconazole} أو كريم |
| {Bacterial vaginosis} | رمادية + ريحة سمك + {clue cells} | {metronidazole} |
| {Trichomonas} | صفرا خضرا رغوية + نقط حمرا بالعنق | {metronidazole} لها ولزوجها |
!why ليش الزوج يتعالج بالـ{trichomonas} بس؟: لأنه ينتقل بالجماع. أما {candida} و{BV} فهي خلل بالبكتيريا الطبيعية عندها.
# 2 {PID} وألم الحوض
> {PID} = التهاب طلع من العنق للرحم والأنابيب (غالبًا {chlamydia} أو {gonorrhea}). العلامة: ألم حوض + حرارة + **ألم لما تحركين العنق**. ولو ما تعالج ← انسداد أنابيب وتأخر حمل و{ectopic}.
| {Situation} | {Answer} |
| {PID} | {ceftriaxone + doxycycline} (± {metronidazole}) |
| ألم فجأة بجهة + ترجيع + كيس مبيض | {torsion} ← [no:{laparoscopy}] فورًا |
| ألم دوري يزيد + ألم جماع + تأخر حمل | {endometriosis} ← {laparoscopy} |
^ ① حامل؟ ② لون الإفرازات وريحتها ③ حرارة + ألم العنق؟ ← {PID} ④ فجأة؟ ← {torsion}
== Gyn oncology & screening
@ المنطق: عنق الرحم: نكشف بدري بالـ{Pap} لأن السرطان ياخذ سنين. أي **شي ينشاف** (كتلة، جرح ينزف) ← {biopsy} مباشرة مو {Pap}. والمبيض: كتلة عند كبيرة ← {CA-125}.
@@ دوري في السؤال على: عمرها · نتيجة الـ{Pap} · {CIN} كم · كتلة تنشاف · نزيف بعد الجماع · بعد سن اليأس
# 1 عنق الرحم
> فيروس {HPV} يغير خلايا العنق شوي شوي: {CIN 1} ← {CIN 2} ← {CIN 3} ← سرطان. عشان كذا الكشف كل 3 سنين يلحقه بدري.
| {Situation} | {Answer} |
| {Pap} غير طبيعي | {colposcopy} + {biopsy} |
| {CIN 2–3} | [ok:{conization}] ({LEEP}) |
| {CIN 1} | متابعة (غالبًا يروح) |
| جرح بالعنق ينزف لما نلمسه | [no:{cervical biopsy}] مباشرة |
%% Friable cervical lesion that bleeds easily. Most appropriate investigation? → Cervical biopsy ✔ || الـ{Pap} للكشف لما ما فيه شي ينشاف. لو فيه شي واضح ← خذي عينة منه.
# 2 المبيض والرحم
| {Situation} | {Answer} |
| كتلة مبيض عند كبيرة | {US} + [ok:{CA-125}] |
| بنت صغيرة + كتلة فيها شعر ودهون | {dermoid} |
| نزيف بعد سن اليأس | {US} ← {endometrial biopsy} |
| {hyperplasia} + {atypia} وما تقدر عملية | {progesterone} مستمر |
^ ① فيه شي ينشاف؟ ← {biopsy} ② {Pap} غير طبيعي؟ ← {colposcopy} ③ {CIN 3}؟ ← {conization} ④ كتلة مبيض عند كبيرة؟ ← {CA-125}
== Urogynecology & other gyn
@ المنطق: التسريب: **مع الكحة** = العضلات ضعيفة ({stress}). **فجأة ما تلحق** = المثانة نشيطة ({urge}). وبعد عملية + ماي مستمر = {fistula}.
@@ دوري في السؤال على: مع الكحة · ما تلحق · ولادات كثيرة · شي نازل · بعد عملية · ماي مستمر
# 1 التسريب والهبوط
| {Type} | الصورة | {Answer} |
| {Stress} | مع الكحة والضحك | {pelvic floor exercises} ← عملية |
| {Urge} | تحس فجأة وما تلحق | تدريب المثانة ← {antimuscarinic} |
| {Overflow} | ما تفضي زين + تقطير | {post-void residual} |
| هبوط ({prolapse}) | شي نازل + ولادات كثيرة | تمارين ← {pessary} ← عملية |
| ماي مستمر بعد عملية أو ولادة صعبة | {vesicovaginal fistula} | — |
%% 60-year-old, recurrent UTI, vaginal bulging, incomplete emptying. Next? → Post-void residual volume ✔ || الهبوط يضغط المثانة فما تفضي ← نقيس اللي يبقى ({PVR}).
!gold القرار: مريضة ترفض فحص أو علاج وهي واعية ← [ok:احترمي رفضها، اكتبيه، وكلميها بعدين].
^ ① مع الكحة ولا ما تلحق؟ ② ما تفضي؟ ← {PVR} ③ بعد عملية + ماي؟ ← {fistula}
