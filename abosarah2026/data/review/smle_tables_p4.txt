# Part 4: Neurology و Preventive
== MS و neuromuscular
> شابة + أعراض عصبية تروح وترجع → MRI with gadolinium (periventricular) → يدعم = oligoclonal bands → relapse = IV methylprednisolone
> MS + العين ما تـadduct = MLF (INO) → تسوء مع الحرارة = Uhthoff
> ضعف + reflexes: UMN + LMN + bulbar = ALS → يزيد آخر اليوم + ptosis = myasthenia (ACh antibodies) → بعد إسهال + areflexia = GBS (protein عالي + خلايا طبيعية)
> رضيع + tongue fasciculations + areflexia = SMA → proximal weakness + reflexes موجودة = congenital myopathy

== Dementia
> نسيان → الجديد أول + الشخصية سليمة = Alzheimer (cholinesterase inhibitor ← ما نفع: memantine)
> stepwise + TIAs = vascular → كلمات بس والذاكرة سليمة = frontotemporal (temporal atrophy)
> hallucinations + parkinsonism + autonomic = Lewy body (لا antipsychotics قوية، quetiapine)

== Seizures
> نوبة → ما صحى بين النوبات = status → benzodiazepine
> أول نوبة → glucose + electrolytes → طاح أو focal أو نعسان = CT
> النوع: jerky = myoclonic (valproate ← levetiracetam) → يوقف ثواني + 3 Hz = absence (ethosuximide) → يطيح = atonic → يمضغ ويحدق = temporal lobe → بالنوم + وجه = Rolandic
> طفل + حرارة + نوبة قصيرة = simple febrile → طمني وعالجي سبب الحرارة

== Stroke
> stroke → CT بدون contrast → نزيف = نزلي SBP لـ140 → ما فيه نزيف + أقل من 4.5 ساعة = tPA
> proximal occlusion + الأعراض باقية + أقل من 24 ساعة = thrombectomy → الأعراض راحت = observation
> بدون tPA = ننزل الضغط بس فوق 220/120
> TIA → carotid أقل من 70% = aspirin + statin → 70% أو أكثر = endarterectomy → شاب + DVT = PFO

== وين الـlesion
> crossed signs (وجه بجهة والجسم بالثانية) = brainstem → بلع + Horner + vertigo = lateral medulla (PICA) → وجه + سمع = AICA → pinpoint pupils = pons
> الوجه والذراع + aphasia = MCA → الرجل + سلوك = ACA → hemianopia = PCA (occipital)
> ضعف متساوي بدون sensory = lacunar (internal capsule) → ما يكتب ولا يفرق يمين ويسار = parietal
