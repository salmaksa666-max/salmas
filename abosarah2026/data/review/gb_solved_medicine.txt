## 📋 RA و Gout و المفصل الحار
- RA جديد ← methotrexate (± hydroxychloroquine + steroid جسر). ما انضبط ← biologic (anti-TNF)
- على biologic + infection ← وقفي الدواء + antibiotics. قبل anti-TNF ← افحصي TB
- مفصل واحد حار + حرارة ← arthrocentesis أول (septic arthritis)
| الكريستال | الشكل |

## 📋 Acute asthma: درجات الشدة
| الدرجة | العلامات |
| Moderate | PEF 50–75%، يتكلم جمل كاملة |
| Acute severe (أي وحدة) | PEF 33–50%، RR 25 أو أكثر، HR 110 أو أكثر، ما يكمل جملة |
| Life-threatening (أي وحدة) | PEF أقل من 33%، SpO2 أقل من 92%، PaO2 أقل من 8 kPa، PaCO2 طبيعي، silent chest، cyanosis، ضعف تنفس، arrhythmia، hypotension، تعب، confusion |
| Near-fatal | PaCO2 عالي أو يحتاج ventilation |
- العلاج بالترتيب: O2 ← salbutamol + ipratropium nebs ← steroids (prednisolone أو hydrocortisone) ← IV magnesium ← ICU و intubation
- PaCO2 طبيعي أو عالي بنوبة asthma = تعبان، مو تحسن
## 📋 Asthma المزمن: درج العلاج
> SABA بس ← low-dose ICS ← ICS + LABA ← زيادة ICS أو LTRA ← specialist (biologics، oral steroid)
- يستخدم SABA أكثر من مرتين بالأسبوع أو يصحى بالليل ← أضيفي ICS
- على ICS وما انضبط ← أضيفي LABA (salmeterol). لا تعطين LABA لحاله أبدًا
- قبل أي زيادة ← شيكي الـtechnique والالتزام والـtriggers
- Exercise-induced ← salbutamol قبل الرياضة
- Occupational ← spirometry أو PEF وقت الشغل وبعيد عنه
- Aspirin + nasal polyps + asthma = Samter (AERD) ← وقفي NSAIDs + montelukast
- Cough-variant asthma ما تحسن ← فكري GERD (PPI) أو postnasal drip
- Asthma + allergic rhinitis ← montelukast مفيد للاثنين
