== Hematology & Oncology
@ المنطق: {Anemia} تسألين "ليش {Hb} نازل؟" ← الـ{MCV} يقول لك وين تدورين. {Bleeding / clot} تسألين "وش الدواء اللي ماخذه؟" ← الدواء يقول لك العلاج. {Oncology} تسألين "فيه طوارئ؟" ({febrile neutropenia} أو {TLS}).
@@ دوري في السؤال على: {MCV} · {ferritin} · {retics} · {LDH} · {Coombs} · {warfarin / heparin} · {INR} · {chemo}
# 1 {Anemia}: الـ{MCV} يحدد الطريق
| {MCV} | {Causes} | الفرق بينها |
| {< 80 (microcytic)} | {Iron deficiency} · {Thalassemia trait} · {Chronic disease} | الـ{ferritin}: واطي ← {IDA} · طبيعي + {RBC} عالي ← {thal trait} · طبيعي أو عالي + مرض مزمن ← {ACD} |
| {> 100 (macrocytic)} | {B12} · {Folate} | فيه أعصاب (تنميل، مشي) ← {B12} · ما فيه ← {folate} |
| {Normal} | {Bleeding} · {Hemolysis} · {CKD} | {retics} عالية ← نزيف أو تكسير · واطية + {CKD} ← {EPO} |
!mem للحفظ: ليش {ferritin}؟ لأنه مخزن الحديد. واطي = خلص الحديد = {IDA} أكيد. والـ{definitive} الكلاسيكي = {bone marrow}.
!gold القرار: عرفتي {IDA}؟ اسألي "من وين ضاع الحديد؟" ← ست تحيض ← الدورة · رجل أو كبيرة بالعمر ← نزيف أمعاء ← [no:{upper + lower endoscopy}]
| {IDA} الحالة | {Treatment} |
| أول مرة | [ok:{oral iron}] |
| {oral} ما نفع، ما تتحمله، أو امتصاص سيئ ({celiac}) | {IV iron} |
# 2 {Hemolysis}: نفس العلامات دايم
- لما الكريات تتكسر يطلع منها {LDH} و {bilirubin}، والـ{haptoglobin} يتلف عليها فينزل، والنخاع يعوض فترتفع {retics}.
- عرفتي إنه تكسير؟ ← السؤال الجاي "ليش؟" ← أول فحص {Direct Coombs}.
| {Disease} | {Clue} |
| {AIHA} | {Coombs +} · فجأة · كبير · ما فيه عائلة · + {platelets} واطية = {Evans} |
| {Hereditary spherocytosis} | {Coombs −} · عائلة · {splenomegaly} · {gallstones} وهو صغير |
| {G6PD} | نوبات بعد فول أو دواء أو عدوى · {Heinz bodies} · {bite cells} |
| {PNH} | بول غامق + {Coombs −} + جلطات |
| {SLE} + هذي العلامات | {hemolytic anemia} |
!warn انتبهي: إسهال + {B12} و {folate} واطيين + سفر هند أو تايلند ← {tropical sprue}. بدون سفر + {villous atrophy} ← {celiac}.
# 3 {Sickle cell}
| {Situation} | {Answer} |
| {Diagnosis} | {Hb electrophoresis} · المرض {HbSS} ما فيه {HbA} |
| {Pain crisis} | {O2 + IV fluids + analgesia} |
| {Acute chest}: ألم صدر + حرارة + {infiltrate} جديد | [no:{exchange transfusion}] |
| نوبات تتكرر | {hydroxyurea} |
| رعشة أو ضيق وقت نقل الدم | وقفي النقل فورًا |
| أبوه {trait} وأمه طبيعية | عيالهم ما يجيهم المرض |
# 4 {Warfarin} و {INR}
- {Warfarin} يوقف {vitamin K} ← عشان كذا علاجه {vitamin K}، والسريع {PCC}.
| {Situation} | {Answer} |
| {INR} عالي بدون نزيف | وقفي جرعة أو قللي ← {INR} بعد يومين |
| نزيف خطير (مخ، أمعاء) | وقفي + {IV vitamin K} + [no:{PCC}] |
| {INR} تغير بعد أعشاب أو دواء جديد | وقفي الأعشاب ← أعيدي {INR} |
| {INR} واطي | زيدي الجرعة |
!mem للحفظ: الهدف {INR 2–3} لـ {AF · DVT · PE} · صمام معدني {2.5–3.5} · {APS} ← {warfarin} مو {DOAC}.
# 5 {DVT · PE · HIT} و {Platelets}
| {Situation} | {Answer} |
| رجل منتفخة | {duplex US} ← موجب ← {DOAC} أو {LMWH} |
| السبب مؤقت (عملية، سفر) | 3 شهور |
| بدون سبب، تكرر، أو {APS} | مدى الحياة |
| حامل | {LMWH} |
| {heparin} من 5–10 أيام + {platelets} نزلت أو جلطة | {HIT} ← وقفي كل {heparin} ← [ok:{argatroban}] |
| بعد فيروس + بس {platelets} | {ITP} |
| حرارة + {confusion} + كلى + {schistocytes} | {TTP} ← {blood film} ← {plasma exchange} |
# 6 {Oncology}: الطوارئ
| {Situation} | {Answer} |
| حرارة + {neutrophils < 500} | {cultures} ← فورًا {cefepime / pip-tazo / meropenem} |
| + {unstable} أو {line} أو {MRSA} | + {vancomycin} |
| حرارة بعد 4–7 أيام | {antifungal} ({voriconazole / amphotericin}) |
| بعد {chemo}: {K} و {phosphate} و {uric} عالية + {Ca} واطي | {TLS} ← {IV fluids} ← {rasburicase} · وقاية {allopurinol} |
| {lymph node} + {B symptoms} | {lymphoma} ← {excisional biopsy} |
^ ① {Anemia}؟ ← {MCV} ← {ferritin} أو علامات التكسير ② {Bleeding}؟ ← وش الدواء؟ ③ {Platelets} واطية؟ ← {heparin} = {HIT} · فيروس = {ITP} · {schistocytes} = {TTP} ④ {chemo}؟ ← {neutropenia} أو {TLS}
== Neurology
@ المنطق: صار فجأة؟ ← شي انسد أو نزف أو تشنج ← صورة ({CT}) أول. صار تدريجي؟ ← {dementia} أو {MS} أو {neuromuscular}. فيه حرارة؟ ← {infection} ({meningitis / encephalitis}) وعلاجها فورًا.
@@ دوري في السؤال على: فجأة · حرارة · يروح ويرجع · يسوء آخر اليوم · بالجهة الثانية · {hours since onset}
# 1 {Stroke}: أول شي {CT} بدون {contrast}
- ليش {CT} أول؟ لأن العلاج عكس بعض: الجلطة تحتاج {tPA} يذوبها، والنزيف الـ{tPA} يقتله. فلازم تعرفين وش هو.
| {Situation} | {Answer} |
| ما فيه نزيف + أقل من 4.5 ساعة | [ok:{tPA}] |
| {large vessel} + أقل من 24 ساعة | {mechanical thrombectomy} |
| نزيف ({ICH}) | نزلي {SBP} لـ{140–160} |
| {TIA} (راحت) | {aspirin + statin} + دوري السبب ({carotid duplex} · {ECG} للـ{AF}) |
| {carotid ≥ 70%} | {carotid endarterectomy} |
| {SAH} + بعد أيام ضعف جديد | {vasospasm} |
!warn انتبهي: قبل {tPA} ← ما فيه نزيف أو {stroke} أو عملية قريب · بدون {tPA} لا تنزلين الضغط إلا فوق {220/120}.
# 2 وين الـ{lesion}؟
| الأعراض | {Location} |
| وجه بجهة والجسم بالثانية | {brainstem} |
| بلع + {Horner} + {vertigo} | {lateral medulla (PICA)} |
| وجه + سمع | {AICA} |
| الرجل أكثر من اليد + سلوك | {ACA} |
| {pinpoint pupils} + وعي نازل | {pons} |
| {diplopia} + العين ما تروح للداخل | {MLF (INO)} ← غالبًا {MS} |
# 3 {Seizures}
| {Situation} | {Answer} |
| تشنج ما وقف ({status}) | [ok:{benzodiazepine (lorazepam)}] ← {phenytoin / levetiracetam} |
| أول تشنج | {glucose + electrolytes} + {CT head} |
| يحدق ويمضغ وما يتذكر | {temporal lobe} ← {carbamazepine} |
| يطيح فجأة | {atonic} |
| حرارة + تشنج + سلوك غريب | {HSV encephalitis} ← [no:{IV acyclovir}] فورًا |
| حامل أو تبي تحمل | {levetiracetam} (مو {valproate}) |

| {Situation} | {Answer} |

| رقبة + تنميل يدين بكبير | {cervical spine MRI} |
| {migraine}: نوبة / متكرر | {NSAID / triptan} · {prophylaxis} |
# 5 {Dementia} و {Delirium}
- الفرق: {dementia} تدريجي على شهور · {delirium} فجأة ويتذبذب ← دوري السبب ({infection}، دواء، {electrolytes}).
| {Type} | {Clue} |
| {Alzheimer} | الذاكرة الجديدة أول ← {rivastigmine / donepezil} |
| {Vascular} | {stepwise} + {stroke} قبل |
| {Frontotemporal} | أصغر + الشخصية والسلوك تتغير |
| {Lewy body} | {hallucinations} + {parkinsonism} |
| {opioids} + {confusion} + {myoclonus} | {opioid neurotoxicity} |
| كحولي + {confusion} + عيون | {Wernicke} ← {thiamine} قبل {glucose} |
# 6 {MS} و {Neuromuscular}
| {Situation} | {Answer} |
| شابة + أعراض تروح وترجع بأماكن مختلفة | {MS} ← {MRI with gadolinium} |
| {MS relapse} | {high-dose IV methylprednisolone} |
| تسوء مع الحر | {Uhthoff} |
| يتطور | {new MRI lesions} |
| ضعف رجلين + مستوى حسي + بول | {spinal cord compression} ← {MRI} طارئ |

== Cardiology
@ المنطق: كل سؤال قلب = 3 أسئلة: وش المرض؟ (الأعراض والـ{ECG}) ← المريض {stable}؟ (ضغط، وعي، ألم) ← وش عنده غيره؟ ({DM · CKD · asthma · pregnancy}) وهذا يختار الدواء.
@@ دوري في السؤال على: {ST elevation} · {unstable} · {EF} · {murmur} وين يروح · {DM / CKD} · {initial / best}
# 1 {Hypertension}: أكدي ثم اختاري الدواء
!mem للحفظ: قراءة وحدة عالية ← أعيدي أو {ABPM} قبل أي دواء · خفيف بدون أذى ← {lifestyle} أول.
| {Patient} | {Drug} |
| {DM} · {CKD} · {proteinuria} · قلب كبير | [ok:{ACE-I}] ({lisinopril, ramipril}) |
| كحة من {ACE-I} | {ARB} ({losartan}) |
| كبير بالعمر أو أسود | {CCB} ({amlodipine}) أو {thiazide} |
| {systemic sclerosis} + ضغط فجأة | {ACE-I} ({renal crisis}) |
| ما انضبط على اثنين | أضيفي الثالث ({thiazide / indapamide}) |
| شاب أو ما ينضبط | {Secondary HTN} |
| {K} واطي | {aldosterone : renin ratio} |
| صداع + تعرق + خفقان | {metanephrines / catecholamines} |
| {creatinine} طلع بعد {ACE-I} | {renal artery stenosis} ← {CT angio} |
!warn انتبهي: {ICH} ← {SBP 140–160} · {ischemic stroke} بدون {tPA} ← لا تنزلينه إلا فوق {220/120} · قبل {tPA} ← أقل من {185/110}.

| {Situation} | {Answer} |

| ألم فجأة للظهر | {aortic dissection} ← أهم سبب {HTN} |

== Pulmonology
@ المنطق: ضيق النفس 4 أسباب: انسداد ({asthma / COPD}) · {infection} ({pneumonia / TB}) · جلطة ({PE}) · سوائل ({effusion / edema}). وبعدها: يكفيه {O2}؟ ولا {NIV}؟ ولا {intubation}؟
@@ دوري في السؤال على: مدخن · حرارة · فجأة · يتحسن بالـ{bronchodilator} · {CO2} · {PEF}
# 1 {Asthma}
- {asthma} انسداد يروح ← عشان كذا التشخيص: {FEV1} يتحسن بعد {bronchodilator}.
| {Situation} | {Answer} |
| نوبة | [ok:{salbutamol + steroids}] |
| شديدة: ما يكمل جملة · {RR > 25} · {PEF < 50%} | + {ipratropium + magnesium} |
| مهددة للحياة: {PEF < 33%} · {CO2} طبيعي أو عالي | {ICU} |
| مزمن ما انضبط | أول شي {adherence + inhaler technique} ← {ICS} ← {ICS + LABA} |
| يسوء بالشغل ويتحسن بالإجازة | {occupational} ← {spirometry} بعد الشغل |
| كحة بعد الأكل + ما ينضبط | {GERD} ← {PPI} |
!warn انتبهي: لو السؤال يقول ما يستخدم الـ{inhaler} صح ← الجواب "علميه الطريقة"، مو "زيدي الدواء".

== GI & Hepatology
@ المنطق: حددي المكان أول: الكبد (صفار، {ascites}، {LFT}) · فوق ({epigastric}، حرقة، نزيف علوي) · تحت (إسهال، دم، {screening}) · البنكرياس (ألم للظهر). وفيه {alarm}؟ ← {endoscopy}.

| {HBV} ساء فجأة | {hepatitis D} |
