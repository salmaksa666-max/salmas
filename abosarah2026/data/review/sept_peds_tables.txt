# Pediatrics
== Vaccines: الجدول و catch-up والموانع
> الجدول (السعودي): birth = BCG + HBV → 2 شهور = DTaP، IPV، Hib، PCV، rota، HBV → 12 شهر = OPV، MMR، varicella، PCV، MCV4 → preschool = MMR + DTaP + OPV
> فاته = catch-up (ما نعيد من الصفر) → 9 شهور ما أخذ شي = BCG + HBV + OPV + DTaP + measles → preterm = العمر الحقيقي (chronological)
> حرارة خفيفة أو URTI أو تورم مكان الإبرة قبل = أعطيه → egg allergy = أعطيه MMR و flu عادي → anaphylaxis من vaccine = لا تعطيه ثاني
> live (MMR، varicella، BCG، OPV) ممنوعة: steroids عالية (2 mg/kg أكثر من أسبوعين) أو chemo أو immunodeficiency → IVIG قريب = أجلي الـlive → HIV مستقر = MMR بحذر

== Neonate: ضيق التنفس
> مولود ضيق تنفس → CS + term + fluid بالـfissures = TTN (O2 30–40% + NGT feeding، يتحسن خلال 24–72 ساعة) → preterm + ground glass = RDS (surfactant)
> meconium + post-term + hyperinflation + patchy = MAS → vigorous = routine care → ما تحسن على ventilation = inhaled nitric oxide (PPHN)
> preterm + apnea تتحسن بالـstimulation = immature respiratory control (mixed apnea) → machinery murmur + wide pulse pressure = PDA (fluid restriction) → بعد CPAP طويل + expiratory wheeze = tracheomalacia
> أم سكري + preterm + grunting = RDS أو sepsis → blood culture + IV antibiotics → أم سكري + Hct 71% بدون أعراض = ما يحتاج شي

== Neonate: الصفار والنزيف والدم
> صفار → أول 24 ساعة أو يزيد بسرعة = hemolysis (unconjugated عالي + Coombs: أمه O أو Rh) → بعد أسبوع + يرضع زين = breast milk jaundice → phototherapy ما نفع = exchange
> صفار + cataract + reducing substance = galactosemia → بعد ما بدأ فواكه = fructose intolerance → acholic stool + butterfly vertebrae = Alagille
> نزيف: platelets واطية + أمه platelets طبيعية = alloimmune (NAIT) → أمها ITP أو SLE = maternal autoimmune (IVIG + platelets) → PT و PTT طويلة = vitamin K → كل شي طبيعي + الحبل تأخر = factor XIII
> subgaleal (يعبر الـsutures) بعد vacuum + Hb واطي = transfusion → أم سكري: hypoglycemia (jittery = glucose)، polycythemia، hypocalcemia

== Stridor و upper airway
> stridor → حرارة خفيفة + barking أو brassy cough + بعد URTI = croup → dexamethasone 0.6 mg/kg (distress = + nebulized epinephrine) → ما تحسن = laryngoscopy
> حرارة عالية + drooling + toxic + tripod = epiglottitis (Hib) → لا تفحصين الحلق، intubate بالـOR → فجأة + بدون حرارة + aphonia أو أكل حب = foreign body
> FB: CXR (expiratory) → rigid bronchoscopy → أشهر مكان right main bronchus → choking وما يقدر يتكلم = 5 back blows + 5 thrusts
> رضيع + stridor يزيد على الظهر ويخف على البطن = laryngomalacia (طمني، FTT أو apnea = ENT) → monophasic expiratory wheeze أو بعد TEF repair أو CPAP طويل = tracheomalacia

== Bronchiolitis و pneumonia
> رضيع أقل من سنة + زكام + wheeze + crackles = bronchiolitis (RSV) → supportive: O2 لو أقل من 90–92% + suction + أكل → apnea أو تعب أو CO2 = intubation
> pneumonia: أحسن علامة = tachypnea (RR) → CXR → lobar = strep pneumoniae → مراهق + bilateral = mycoplasma → رضيع + conjunctivitis + staccato cough = chlamydia (azithromycin)
> pneumonia ما تحسن على antibiotics = effusion أو empyema (أخطر علامة: persistent fever) → stony dull = pleural effusion

> بدون exudate = home rest → sandpaper rash = scarlet fever → 6–7 نوبات بالسنة + snoring = adenotonsillectomy
> زكام 7–8 مرات بالسنة وينتهي لحاله = طبيعي (hand hygiene) → sinusitis أكثر من 10 أيام = amoxicillin (ما تحسن = amox-clav)
> OME مستمر + سمع = tubes → tubes + سباحة + otorrhea = pseudomonas
