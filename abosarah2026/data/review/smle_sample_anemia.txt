# Part 1: Hematology (عينة بالطريقة الجديدة)
== الخريطة 1: أول سؤال تسألينه بأي أنيميا: كم الـMCV؟
> Hb واطي → شوفي الـMCV
> MCV واطي (microcytic) → خريطة 2: IDA ولا thalassemia ولا lead ولا chronic disease
> MCV طبيعي + retics عالية → الجسم يصنع بس الدم يتكسر أو ينزف → خريطة 3: hemolysis
> MCV عالي (macrocytic) → B12 أو folate → دوري سبب سوء الامتصاص بالأمعاء
== الخريطة 2: Microcytic: أربع أسباب، كل واحد له مفتاح
> MCV واطي → ferritin واطي → IDA (أكل: حليب بقر وبسكويت، أو نزيف)
> MCV واطي → ferritin طبيعي + RBC عالي أو طبيعي + target cells → thalassemia (Hb electrophoresis)
> MCV واطي أو طبيعي → basophilic stippling + pica + خطوط كثيفة بالعظم → lead poisoning
> MCV واطي → ferritin عالي + مرض مزمن (SLE، sarcoid، CKD) → anemia of chronic disease

== الخريطة 3: Hemolysis: هل الدم يتكسر؟ وليش؟
> علامات hemolysis: retics و LDH و indirect bilirubin عالية + haptoglobin واطي → أول فحص: Coombs
> Coombs إيجابي → AIHA → steroids
> Coombs سلبي + spherocytes أو gallstones أو طحال → hereditary spherocytosis → osmotic fragility
> Coombs سلبي + بعد أكل (فول) أو دواء + bite cells → G6PD
> Hb S بالـsmear → sickle cell → خريطة 4

== الخريطة 4: Sickle cell
> Sickle → التشخيص: Hb electrophoresis → HbSS: ما فيه Hb A أبدًا → HbAS (trait): Hb A موجود
> Sickle + ألم وتورم إصبع → dactylitis
> Sickle + hypoxia + infiltrate جديد → acute chest → exchange transfusion
