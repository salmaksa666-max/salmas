# Obstetrics
== Early pregnancy: الإجهاض
> نزيف بأول الحمل → شوفي الـos والـUS → os مقفل + نبض = threatened → os مفتوح + tissue باقي = incomplete (evacuation) → طلع كله + رحم فاضي = complete → جنين ميت + os مقفل = missed
> بعد إجهاض + شاحبة + نزيف = عالجي الصدمة (blood) وبعدين evacuation → بعد D&C + amenorrhea = Asherman (hysteroscopy)
> السبب: أول trimester = chromosomal → recurrent (3 أو أكثر) = karyotyping للزوجين → mid-trimester بدون ألم = cervical insufficiency (cerclage 12–14 أسبوع)

== Ectopic pregnancy
> ألم حوض + amenorrhea → أول شي: β-hCG + CBC + urine → US: كيس بالرحم؟ لا + hCG فوق discriminatory = ectopic → ما شي بالرحم ولا برا = PUL
> ectopic: unstable أو ruptured = surgery → stable + صغير + hCG واطي = methotrexate → الـtube الثانية سليمة = salpingectomy (بعد IVF أو الثانية مريضة = salpingostomy)
> hCG ما نزل بعد العلاج = persistent → جرعة MTX ثانية أو surgery → خطر يرجع ectopic = 10–15%

== Molar pregnancy و GTN
> نزيف + uterus أكبر من العمر + hCG عالي جدًا + snowstorm = mole → suction evacuation → hCG كل أسبوع لين يصفر → بعدها شهري (complete: 6 شهور)
> hCG يطلع أو ثابت أو نزيف بعد الـevacuation = GTN → metastatic workup (بدون biopsy) → theca lutein cysts + hCG عالي = high risk
> حمل بعد mole = early US بالحمل الجاي → منع الحمل وقت المتابعة = OCP

== Hypertension بالحمل
> ضغط 140/90 أو أكثر بعد 20 أسبوع + protein أو أعراض = preeclampsia → severe: 160/110 أو صداع أو زغللة أو ألم بطن أو platelets واطية
> ضغط 160/110 → خفضيه: hydralazine أو labetalol IV → seizure أو severe = magnesium sulfate → 37 أسبوع أو أكثر = deliver (induction)
> أقل من 34 أسبوع + severe = steroids + Mg + deliver لما تستقر → HELLP: platelets أقل من 100,000 أهم علامة

== Antepartum hemorrhage
> نزيف بآخر الحمل → بدون ألم = previa (لا vaginal exam، US يحدد مكان الـplacenta) → مع ألم + رحم قاسي = abruption (smoking، HTN، cocaine)
> previa + مستقرة = observe لين 37 أسبوع ثم CS → أقل من 34 = steroids → unstable أو نزيف ما وقف = CS فورًا (بعد جرعة dexamethasone لو تمديه)
> abruption + DIC = cryoprecipitate → توقف contractions فجأة + نزيف + صدمة = uterine rupture → abruption قبل = high risk + serial US

== Labor: CTG و المراقبة
> CTG: baseline 110–160 + variability 5–25 + accelerations = طبيعي → early decelerations = ضغط الرأس (طبيعي) → late = placental insufficiency → variable = cord
> على oxytocin + CTG سيئ = وقفي oxytocin أول → late decels = غيري وضعيتها + O2 + fluids → sinusoidal = fetal anemia (CS) → prolonged decel = قيمي بعد 2–3 دقايق، ما رجع = deliver
> low risk = intermittent auscultation → high risk (HTN، IUGR، DM) = continuous CTG → أخطر علامة = tachycardia 180 أو غياب variability
