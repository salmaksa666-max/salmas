== الأملاح والكلى
> ترجيع أو NG suction → يضيع H و Cl → metabolic alkalosis + K واطي → IV saline + KCl
> Na واطي → شوفي الحجم: edema (HF، cirrhosis) = hypervolemic → thiazide عند كبير = أشهر سبب → بعد عملية + D5W = SIADH أو hypotonic → fluid restriction
> K عالي → peaked T → wide QRS → sine wave → TLS: ضعف = K عالي، ألم عضلات = Ca واطي
> CKD → phosphate عالي → Ca واطي → PTH عالي → قللي الطماطم والموز (K)

== Diabetes
> سكر عالي → C-peptide واطي = type 1 → طبيعي أو عالي = type 2 → metformin أول
> أعراض + fasting 7 أو أكثر أو random 11.1 = سكري → بدون أعراض = أعيدي التحليل أو OGTT
> DKA (glucose عالي + ketones + HCO3 أقل من 15) → IV fluids + IV insulin → HCO3 طبيعي = مو DKA
> hypoglycemia بالليل = قللي الـbasal → بعد الأكل أو الرياضة = قللي الـbolus (أو كلي قبلها)

# Part 2: Cardiology
== Ischemic heart disease
> ألم صدر → ECG: ST elevation أو LBBB جديد = STEMI → PCI (لو بعيد: thrombolysis خلال 12 ساعة) → inferior MI = right-sided ECG
> ST depression + troponin = NSTEMI → aspirin + clopidogrel + heparin
> ألم مع الجهد + ECG طبيعي = exercise ECG → ما يقدر يمشي = dobutamine stress echo → ECG ما يتقرأ = myocardial perfusion
> بعد MI بـ3–5 أيام + murmur جديد + صدمة = VSD rupture (أو papillary muscle = MR)
> قبل thrombolysis = تأكدي ما فيه نزيف أو stroke قريب

> طفل SVT → unstable أو طاح أو وعي نازل = synchronized cardioversion → stable = adenosine
> بعد فيروس + gallop + كبد كبير = myocarditis → echo (أول فحص: ECG) → إغماء وقت الجري = echo (HCM)

== الصمامات
> systolic → ejection يروح للـcarotids = AS → pansystolic يروح للـaxilla = MR → click + late systolic = MVP
> diastolic → early + wide pulse pressure = AR → mid-diastolic rumble بالـapex = MS → يزيد بالشهيق = right side (PR أو TR)
> AS بدون أعراض = follow-up echo → أعراض (syncope، angina، SOB) أو EF واطي = valve replacement
> prophylaxis قبل الأسنان = صمام صناعي أو endocarditis قبل → MVP أو MR لحالها = ما يحتاج
> rheumatic: acute = MR → chronic = MS → أسوأ صمام بالحمل = MS
