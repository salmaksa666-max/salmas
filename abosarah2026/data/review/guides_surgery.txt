== Trauma & ATLS
@ المنطق: الحادث كله ترتيب: **{A} ← {B} ← {C} ← {D}**. اللي يموت أسرع نعالجه أول: مجرى الهواء يقتل بدقايق، بعده التنفس، بعده النزيف. فلا تختارين أشعة أو {CT} قبل ما يكون {ABC} مضبوط.
@@ دوري في السؤال على: {GCS} · صوت التنفس · القصبة مايلة · ضغط ونبض · وجه مكسور · بطن · حوض
# 1 مجرى الهواء ({A})
> اسألي: **يقدر يحمي مجرى هواه؟** لو {GCS ≤ 8} أو حروق بالوجه أو دم بالفم ← لازم أنبوب ({intubation}) مع حماية الرقبة. ولو الوجه مكسور كله وما قدرنا ندخل الأنبوب ← نفتح من الرقبة ({cricothyroidotomy}).
!mem للحفظ: {GCS} = عيون 4 + كلام 5 + حركة 6. {GCS ≤ 8} ← [no:{intubate}].
%% 20-year-old after MVA, multiple facial fractures, failed attempts to intubate. Next? → Surgical cricothyroidotomy ✔ || الوجه مكسور فالفم مو طريق ← ندخل من الرقبة.
# 2 التنفس ({B}): اسمعي الصدر
| الصورة | التشخيص | {Answer} |
| صوت مختفي + القصبة مايلة للجهة الثانية + ضغط واطي | {tension pneumothorax} | [no:{needle decompression}] فورًا (بدون أشعة) ← {chest tube} |
| صوت مختفي + **{dullness}** + ضغط واطي | {hemothorax} | {chest tube} |
| جزء من الصدر يتحرك عكس | {flail chest} | {O2} + مسكن ± {ventilation} |
| طعنة + صوت قلب مكتوم + عروق الرقبة منتفخة + ضغط واطي | {cardiac tamponade} | {pericardiocentesis} |
!why ليش {tension} بدون أشعة؟: لأن الهواء المحبوس يضغط القلب ويوقفه خلال دقايق. التشخيص من الفحص، والأشعة تضيع وقته.
# 3 النزيف ({C})
> الضغط واطي بعد حادث = **ينزف لين يثبت العكس**. وين ممكن يضيع الدم؟ الصدر · البطن · الحوض · الفخذ · برا. عشان كذا: وقفي النزيف اللي تشوفينه ← سوائل ودم ← دوري وينه.
| {Situation} | {Answer} |
| بطن + ضغط واطي | [ok:{FAST}] ← دم + ضغط واطي ← {laparotomy} |
| بطن + مستقر | {CT} مع {contrast} |
| حوض مكسور ويتحرك + ضغط واطي | {pelvic binder} |
| نزيف ظاهر | ضغط مباشر |
!why ليش {FAST} مو {CT} لما الضغط واطي؟: لأن {FAST} بجانب السرير بدقيقتين، و{CT} يعني تطلعينه وهو ممكن يموت بالطريق. الـ{CT} بس للمستقر.
# 4 الراس ({D})
| {Situation} | {Answer} |
| ضربة + صحى شوي + بعدين تدهور | {epidural} ← {evacuation} |
| علامات ضغط بالمخ (نبض بطيء + ضغط عالي) | ارفعي الراس + {hyperventilation} مؤقت + {mannitol} |
^ ① {A}: يحمي مجرى هواه؟ ② {B}: اسمعي الصدر ③ {C}: ضغط واطي؟ ← وين النزيف ← {FAST} ④ {D}: {GCS}
== Burns, wounds & soft tissue
@ المنطق: الحروق: **مجرى الهواء أول** (لو استنشق دخان)، بعدين **السوائل** حسب مساحة الحرق. الجروح: **نظفي** قبل ما تخيطين، والوسخ القديم ما ينخاط.
@@ دوري في السؤال على: حريق بمكان مسكر · بلغم أسود · صوت مبحوح · مساحة الحرق · كم ساعة للجرح · وسخ · تطعيم
# 1 الحروق
> الدخان الحار يحرق مجرى الهواء من داخل، والورم يزيد بالساعات الجاية. عشان كذا لو فيه علامات ({carbonaceous sputum}، بحة، شعر وجه محروق، {stridor}) ← [no:{intubate}] **بدري** قبل ما يسكر.
| {Situation} | {Answer} |
| علامات استنشاق | {intubation} بدري |
| حرق كبير (فوق 20% كبار) | سوائل {Parkland}: 4 × الوزن × النسبة (نصها بأول 8 ساعات) |
| حرق دائري بالصدر أو الطرف | {escharotomy} |
%% 29-year-old after house fire, facial burns, singed nasal hair, hoarse voice. Next? → Elective intubation ✔ || علامات استنشاق ← نحمي مجرى الهواء قبل ما يورم.
# 2 الجروح
| {Situation} | {Answer} |
| جرح نظيف وجديد | نظفي ← خياطة |
| جرح وسخ أو قديم | {debridement} + نخليه مفتوح أو خياطة متأخرة |
| جرح + لون أسود + غاز تحت الجلد | {gas gangrene} ({Clostridium perfringens}) ← [no:{debridement}] + {penicillin} |
| احمرار ينتشر بسرعة + ألم أكثر من الشكل | {necrotizing fasciitis} ← عملية فورًا |
| جرح عند مشلول ثابت بمكان | {pressure ulcer} ← [ok:توزيع الضغط] |
!why ليش الألم أكثر من الشكل مخيف؟: لأن الالتهاب ماشي تحت الجلد على الأغشية، والجلد فوق لسا شكله بسيط. فلا تنتظرين يبان.
^ ① حرق؟ ← استنشاق؟ ← سوائل ② جرح؟ ← نظيف ولا وسخ ③ أسود وغاز؟ ← {debridement}
== Breast
@ المنطق: أي كتلة بالثدي **ثلاث خطوات** ({triple assessment}): فحص ← صورة ← عينة. والصورة تعتمد على **العمر**: تحت 30–35 ← {US}، فوقها ← {mammogram}.
@@ دوري في السؤال على: العمر · كتلة تتحرك · إفرازات دم · {BIRADS} · {BRCA} · قريبة مصابة
# 1 الكتلة
> الثدي عند الصغيرة **كثيف**، فالـ{mammogram} ما يشوف زين ← {US}. عند الكبيرة الثدي دهون أكثر ← {mammogram} يشوف. وبعد الصورة لو فيها شك ← {core biopsy} ({tru-cut}).
| {Situation} | {Answer} |
| بنت صغيرة + كتلة ناعمة تتحرك | {fibroadenoma} ← {US} ← طمني أو شيليها |
| كتلة عند كبيرة | {mammogram} + {US} ← {core biopsy} |
| كيس فيه سوائل | {aspiration} ← لو رجع أو فيه دم ← عينة |
%% Female with a 3×4 cm breast mass. Next? → Tru-cut biopsy ✔ || كتلة واضحة كبيرة ← نحتاج نسيج نعرف وش هي.
# 2 الإفرازات والكشف
| {Situation} | {Answer} |
| إفرازات دم من قناة وحدة | {intraductal papilloma} ← صورة |
| إفرازات خضرا من الجهتين + قنوات متوسعة | {duct ectasia} ← طمني |
| {BIRADS 1–2} | طمني |
| {BIRADS 3} | صورة بعد 6 شهور |
| {BIRADS 4–5} | [no:{biopsy}] |
| {BRCA+} | {MRI} كل سنة |
!why ليش {MRI} لـ{BRCA}؟: لأنهم صغار (ثدي كثيف) وخطرهم عالي، والـ{MRI} أدق شي يلقط السرطان بدري.
^ ① كم عمرها؟ ← {US} ولا {mammogram} ② فيه شك؟ ← {core biopsy} ③ {BIRADS} كم؟
== Thyroid, parathyroid & neck
@ المنطق: كتلة بالرقبة **تتحرك مع البلع** = من الغدة الدرقية ← {US} ← {FNA}. وبعد العملية: صوت مبحوح = عصب · تنميل = {calcium} · ورم بالرقبة + ضيق = دم محبوس.
@@ دوري في السؤال على: تتحرك مع البلع · مع اللسان · حجمها · {TSH} · بعد العملية كم ساعة · بحة · تنميل
# 1 الكتلة
> أول شي {TSH}: لو واطي (الكتلة شغالة زيادة) ← نادرًا سرطان ← {scan}. لو طبيعي ← {US} ← لو أكبر من 1–1.5 سم أو شكلها مشبوه ← [ok:{FNA}].
| {Situation} | {Answer} |
| كتلة درقية | {TSH} + {US} ← {FNA} |
| كتلة بالنص تتحرك مع **اللسان** | {thyroglossal cyst} ← {Sistrunk} |
| كتلة على جنب الرقبة قدام العضلة | {branchial cyst} |
%% Neck mass 2.2 cm moving with swallowing. Next? → FNA ✔ || كتلة درقية بحجم يستاهل ← ناخذ عينة بالإبرة.
# 2 بعد العملية
| الصورة | السبب | {Answer} |
| ورم بالرقبة + ضيق بعد ساعات | دم محبوس يضغط | [no:افتحي الجرح بالسرير] |
| صوت مبحوح | {recurrent laryngeal nerve} | {laryngoscopy} |
| تنميل + {Chvostek} | {calcium} نزل (الغدد الجار درقية انصابت) | {IV calcium gluconate} |
| {calcium} ما يرتفع مع العلاج | — | افحصي {magnesium} |
!why ليش {magnesium}؟: لأن الجسم ما يقدر يطلع {PTH} لو {magnesium} واطي، فيبقى {calcium} واطي مهما عطيتيه.
^ ① تتحرك مع البلع؟ ← {TSH} + {US} + {FNA} ② بعد العملية: ضيق = دم · بحة = عصب · تنميل = {calcium}
== Upper GI, hepatobiliary & pancreas
@ المنطق: ألم البطن الفوق: **وين بالضبط؟ وبعد إيش؟** يمين فوق بعد الدهون = مرارة. بالنص للظهر + ترجيع = بنكرياس. فجأة وقوي + بطن قاسي = قرحة انثقبت.
@@ دوري في السؤال على: بعد أكل دسم · {Murphy} · صفار · حرارة · للظهر · {NSAIDs} · بطن قاسي · {lipase}
# 1 المرارة
> الحصوة تسد المخرج ← ألم. لو راحت بساعات = {biliary colic}. لو بقت ← التهاب = {cholecystitis} (حرارة + {Murphy}). لو نزلت للقناة الرئيسية ← صفار. ولو القناة التهبت ← {Charcot}: حرارة + صفار + ألم = {cholangitis} (خطير).
| {Situation} | {Answer} |
| ألم بعد أكل دسم يروح بساعات | {biliary colic} ← {US} ← {cholecystectomy} |
| ألم + حرارة + {Murphy} | {cholecystitis} ← {US} ← {antibiotics} + عملية |
| صفار + حصوة بالقناة | {ERCP} |
| حرارة + صفار + ألم | {cholangitis} ← سوائل + {antibiotics} + [no:{ERCP}] |
!mem للحفظ: أول فحص للمرارة دايم {US}.
# 2 البنكرياس
> سببين أشهر: **حصوات** و**كحول**. التشخيص: ألم نموذجي + {lipase} فوق 3 مرات (أو صورة). والعلاج **دعم**: سوائل كثير + مسكن + أكل بدري لو يقدر.
| {Situation} | {Answer} |
| التشخيص | [ok:{serum lipase}] |
| كيس بعد 4–6 أسابيع ويكبر ويعور | {pseudocyst} ← {endoscopic drainage} |
| بنكرياس بسبب حصوة | شيلي المرارة بنفس التنويم |
# 3 المعدة: القرحة المثقوبة
> {NSAIDs} أو {H. pylori} تسوي قرحة، ولو انثقبت يطلع هواء وحمض للبطن ← ألم فجأة قوي + بطن قاسي زي الخشب.
%% Woman on NSAIDs for RA, sudden severe epigastric pain, rigid abdomen. First investigation? → Erect chest X-ray ✔ || نبي نشوف الهواء تحت الحجاب الحاجز = ثقب.
^ ① وين الألم وبعد إيش؟ ② مرارة؟ ← {US} ③ بنكرياس؟ ← {lipase} + سوائل ④ فجأة + قاسي؟ ← {erect CXR}
== Appendix, bowel & acute abdomen
@ المنطق: انسداد: **ترجيع + انتفاخ + ما يطلع ريح** ← سببه غالبًا التصاقات (لو عنده عملية قبل) أو فتق. وكبير بالعمر + {AF} + ألم أكثر من الفحص = الأمعاء ما يجيها دم.
@@ دوري في السؤال على: عملية قبل · {AF} · ألم أكثر من الفحص · ورم يمين تحت · صديد · كبير بالعمر · دم بالبراز
# 1 الزايدة
> تبدأ حول السرة ← تنتقل يمين تحت. وبعد أيام ممكن يتكون حولها **كتلة** ({phlegmon}) أو **صديد** ({abscess}).
| {Situation} | {Answer} |
| زايدة واضحة | {appendectomy} |
| مو واضحة | {US} (طفل وحامل) أو {CT} ← أو تنويم ومراقبة |
| كتلة بدون صديد | [ok:{antibiotics}] بدون عملية الحين |
| صديد | {percutaneous drainage} + {antibiotics} |
!why ليش ما نشيلها لما فيه كتلة؟: لأن الأمعاء لاصقة ببعض والعملية وقتها تضر أكثر. نهديها بالمضاد وبعدين نقرر.
# 2 الانسداد والدم
| {Situation} | {Answer} |
| انسداد + عملية قبل + مستقر | التصاقات ← [ok:{NPO} + {NG} + سوائل] |
| انسداد + حرارة أو ألم مستمر أو نبض سريع | اختناق ← عملية |
| كبير + {AF} + ألم قوي والبطن لين | {mesenteric ischemia} ← {CT angio} |
| كبير + إمساك + انتفاخ كبير + {coffee bean} | {sigmoid volvulus} ← {endoscopic decompression} |
%% Elderly with AF, sudden severe abdominal pain. Diagnosis? → Mesenteric ischemia || الجلطة من القلب سدت شريان الأمعاء. الألم قوي بس الفحص بسيط لأن البريتون لسا ما التهب.
# 3 القولون
| {Situation} | {Answer} |
| ألم يسار تحت + حرارة + كبير | {diverticulitis} ← {CT} ← {antibiotics} |
| فوق 45 بدون أعراض | {colonoscopy} للكشف |
| {polyp} انشال كامل وسليم | متابعة |
^ ① انسداد؟ ← عملية قبل؟ ← {NPO} + {NG} · علامات اختناق ← عملية ② {AF} + ألم؟ ← {ischemia} ③ زايدة + كتلة؟ ← مضاد · صديد ← {drainage}
== Anorectal & hernia
@ المنطق: الفتق: **يرجع ولا لا؟** يرجع = عملية مرتبة. ما يرجع ويعور = خطر الاختناق ← عملية مستعجلة. والشرج: ألم حاد مع البراز = شق · نزيف بدون ألم = بواسير · ورم يعور + حرارة = خراج.
@@ دوري في السؤال على: يرجع؟ · يعور؟ · مع الكحة · فوق ولا تحت الرباط · ألم مع البراز · دم بدون ألم · ساعة كم
# 1 الفتق
| {Situation} | {Answer} |
| يرجع وما يعور | [ok:{elective mesh repair}] |
| ما يرجع + ألم + ترجيع | {strangulated} ← عملية فورًا |
| تحت الرباط عند ست | {femoral} ← عملية دايم (يختنق كثير) |
| سرة عند طفل فوق 4–5 سنين | عملية |
!why {direct} ولا {indirect}؟: سكري الفتحة الداخلية بإصبعك واطلبي منه يكح: **ما طلع** = {indirect} (يطلع من الفتحة اللي سكرتيها). **طلع** = {direct} (من الجدار الضعيف).
# 2 الشرج
| {Situation} | {Answer} |
| ألم حاد مع البراز + دم قليل + خلف بالنص | {anal fissure} ← ألياف + كريم |
| دم أحمر بدون ألم | {hemorrhoids} |
| ورم يعور + حرارة | {abscess} ← [no:{incision & drainage}] |
| فتحة تطلع صديد | {fistula} ← {MRI} لو معقد |
| فتحات كثيرة + بطن + نزول وزن | {Crohn} ← {colonoscopy} |
!mem للحفظ: {Goodsall}: الفتحة الخارجية **ورا** ← الداخلية بالنص من ورا (ساعة 6).
^ ① يرجع؟ ← مرتبة · ما يرجع ويعور ← فورًا ② الشرج: ألم؟ ← شق · بدون ألم ← بواسير · حرارة ← خراج
== Vascular
@ المنطق: الشريان: **مزمن** (ألم مع المشي = {claudication}) ← نوقف التدخين ونمشيه. **فجأة** (بارد، شاحب، ما فيه نبض) ← جلطة ← تنقذين الرجل خلال ساعات.
@@ دوري في السؤال على: ألم مع المشي · ألم وهو مرتاح · {ABI} · فجأة · {AF} · كتلة تنبض · {TIA}
# 1 الأرجل
| {Situation} | {Answer} |
| ألم مع المشي يروح بالراحة | {claudication} ← {ABI} ← وقف تدخين + مشي + {statin} + {aspirin} |
| ألم وهو مرتاح أو جرح ما يطيب | خطر ← تصوير ({angio}) ← توسيع أو {bypass} |
| فجأة: بارد + شاحب + ما فيه نبض ({6 Ps}) | {acute limb ischemia} ← {heparin} ← فتح الشريان |
!why ليش ألم الراحة أخطر؟: لأنه يعني الدم ما يكفي الرجل حتى وهي ما تشتغل. هذا قبل الموت بخطوة.
# 2 الشريان الأورطي والرقبة
| {Situation} | {Answer} |
| كتلة تنبض بالبطن + مستقر | {CT} مع {contrast} |
| كتلة تنبض + ألم + ضغط واطي | انفجار ← [no:عملية فورًا] |
| {TIA} + تضيق {carotid} 70% أو أكثر | {carotid endarterectomy} |

^ ① مع المشي ولا وهو مرتاح؟ ② فجأة + بارد؟ ← {heparin} ③ كتلة تنبض؟ ← مستقر = {CT} · مو مستقر = عملية
== Urology
@ المنطق: الخصية: ألم **فجأة** عند صغير = {torsion} لين يثبت العكس، والوقت = الخصية. الحصوة: ألم يجي ويروح من الجنب للمغبن + دم بالبول.
@@ دوري في السؤال على: فجأة · عمره · {cremasteric} · كم ساعة · ألم من الجنب للمغبن · حرارة · ما يقدر يبول
# 1 الخصية
> الخصية التفت ← الدم انقطع. **أول 6 ساعات** نقدر ننقذها غالبًا، بعدها تموت. عشان كذا [no:عملية فورًا] بدون انتظار صور.
| {Situation} | {Answer} |
| ألم فجأة + خصية مرفوعة + {cremasteric} مفقود | {torsion} ← عملية + تثبيت **الخصيتين** |
| ألم تدريجي + حرارة + حرقان | {epididymitis} ← {antibiotics} |
| ورم ما يعور وينير بالضوء | {hydrocele} |
| زي كيس ديدان فوق الخصية | {varicocele} |
!why ليش نثبت الثانية بعد؟: لأن السبب (الخصية معلقة بشكل يخليها تلف) غالبًا بالجهتين.
# 2 الحصوات والبروستات
| {Situation} | {Answer} |
| ألم يجي ويروح + دم بالبول | {CT KUB} بدون {contrast} ← مسكن ({NSAIDs}) |
| حصوة + حرارة | [no:{drainage}] ({stent} أو {nephrostomy}) + {antibiotics} |
| ما يقدر يبول + مثانة منتفخة | {catheter} |
| كبير + يقوم بالليل + تدفق ضعيف | {BPH} ← {alpha blocker} |
^ ① خصية + فجأة؟ ← عملية ② حصوة + حرارة؟ ← {drainage} ③ ما يبول؟ ← {catheter}
== Orthopedics
@ المنطق: كسر مفتوح = **تلوث** ← مضاد بأول ساعة + تنظيف بالعملية. أي كسر: افحصي **النبض والأعصاب** تحت الكسر. وألم يزيد مع شد العضلة = {compartment}.

# 1 الكسور

== Perioperative, anesthesia & post-op
@ المنطق: حرارة بعد العملية: **كم يوم صار؟** كل يوم له سبب. وأول شي بأي حرارة بعد العملية: [ok:افحصي الجرح].
@@ دوري في السؤال على: كم يوم بعد العملية · الجرح · ضيق نفس · رجل منتفخة · ما يتحرك · تخدير · ما يبول
# 1 الحرارة بعد العملية
> رتبيها بالأيام (الـ{5 Ws}):
| اليوم | السبب | {Answer} |
| أول يوم أو يومين | {atelectasis} (الرئة ما انفتحت زين) أو التخدير | تنفس عميق ومشي |
| 3–5 | التهاب بول أو صدر | {urine} + {CXR} |
| 5–7 | الجرح · أو تسريب من الوصلة | افحصي الجرح |
| 5–10 | جلطة ({DVT / PE}) | {duplex} أو {CT angio} |
%% Post-op day 4, fever 38.9. Initial? → Review the surgical site ✔ || أبسط وأول شي: شوفي الجرح بعينك.
!warn انتبهي: بعد عملية أمعاء + يوم 5–7 + ألم بطن وحرارة = تسريب من الوصلة ({anastomotic leak}) ← {CT}.
# 2 قبل العملية والتخدير
| {Situation} | {Answer} |
| {aspirin} أو {clopidogrel} | وقفيهم قبل 5–7 أيام (إلا لو عنده {stent} جديد) |
| {warfarin} | وقفيه 5 أيام ← {INR} |
| حرارة عالية + عضلات قاسية بعد التخدير | {malignant hyperthermia} ← {dantrolene} |
| ما يبول بعد العملية | افحصي الـ{catheter} أول |
!why ليش الـ{catheter} أول؟: لأن أسهل وأشهر سبب إنه مسدود أو مثني. قبل ما تفكرين بالكلى.
^ ① كم يوم؟ ← السبب ② حرارة؟ ← افحصي الجرح أول ③ ما يبول؟ ← الـ{catheter}
== ENT, eye & neurosurgery
@ المنطق: الرعاف: **ضغط** على مقدمة الأنف أول. أي ألم عين أو نقص نظر فجأة ← طوارئ عيون. وبعد ضربة راس: الـ{GCS} يقرر.
