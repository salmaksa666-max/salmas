## الخطوة الأولى دايمًا
> أعراض stroke → Non-contrast CT (يستبعد النزيف) → ما فيه نزيف → كم ساعة؟ والأعراض باقية؟
## Acute ischemic stroke: الوقت يقرر
| الوضع | الجواب |
| 4.5 ساعة أو أقل + CT ما فيه نزيف + ما فيه مانع | tPA (alteplase) |
| Large vessel occlusion (proximal) + الأعراض باقية + أقل من 24 ساعة | Mechanical thrombectomy |
| LVO + أقل من 4.5 ساعة | tPA + thrombectomy |
| الأعراض راحت (resolved) | Observation + workup + الوقاية |
| فات الوقت أو CT فيه hypodensity واضح | Aspirin |
## الضغط
| الحالة | متى ننزله |
| قبل tPA | لو أعلى من 185/110 (يعني 160/95 ما يأخر tPA) |
| بدون tPA | بس لو أعلى من 220/120 |
| ICH (نزيف) | SBP حوالي 140، لا تنزلينه تحت 130 (المصدر 140–160 ⚠) |
## بعد TIA: الوقاية
| Carotid stenosis | العلاج |
| أقل من 50% | Aspirin + statin |
| 50–69% | Medical (المصدر). بعض المراجع: endarterectomy ⚠ |
| 70–99% | Endarterectomy خلال أسبوعين |
| 100% مسدود | لا عملية |
- أول فحص بعد TIA → carotid duplex
- ABCD2 من 0 إلى 3 → aspirin بس. 4 أو أكثر → aspirin + clopidogrel لمدة 21 يوم
- TIA + AF → مميع (oral anticoagulant) مو aspirin
## Stroke بشاب
- كسر أو DVT أو PE ثم stroke → PFO (paradoxical embolus) → bubble echo
- Rheumatic fever قديم → mitral stenosis → AF → embolus
- علاجه warfarin، ما نعطي DOAC مع mitral stenosis
- 🔁 لو الأعراض راحت → observation. لو باقية + proximal occlusion → thrombectomy

== Meningitis: read the CSF
q: Fever **1 month**, confusion, lymphocytes 73%, protein **very high**, glucose low-normal | TB meningitis @SWR-0246
q: From **India**, headache **3 weeks**, seizure, lymphocytes, glucose **1.2** | TB meningitis @SWR-0866

q: Seizure + ↓LOC after viral illness, lymphocytes | Acyclovir @SWR-0637
q: Flex the neck → **hips and knees flex** | Brudzinski sign @SWR-1044
idea:
| النوع | الخلايا | Glucose | Protein |
| Bacterial | Neutrophils كثير | واطي جدًا | عالي |
| Viral | Lymphocytes | طبيعي | طبيعي أو شوي |
| TB | Lymphocytes | واطي | عالي جدًا |
| Fungal (crypto) | Lymphocytes | واطي | عالي |
| HSV encephalitis | Lymphocytes + RBC | طبيعي | طبيعي أو شوي |
## كيف نحسب الـCSF glucose ratio
> سكر الـCSF ÷ سكر الدم (نفس الوحدة) = الـratio
| الـratio | المعنى |
| 0.6 تقريبًا | طبيعي (يعني CSF ثلثين سكر الدم) |
| أقل من 0.4 | واطي → bacterial أو TB أو fungal |
## أمثلة
| سكر الـCSF | سكر الدم | الحساب | النتيجة |
| 1.2 mmol/L | 6 mmol/L | 1.2 / 6 = 0.2 | واطي |
| 30 mg/dL | 150 mg/dL | 30 / 150 = 0.2 | واطي |
| 60 mg/dL | 100 mg/dL | 60 / 100 = 0.6 | طبيعي |
| 60 mg/dL | 300 mg/dL | 60 / 300 = 0.2 | واطي (فخ) |
- الفخ: سكر الـCSF يبان طبيعي بس سكر الدم عالي، فالـratio يطلع واطي
- لو ما عطاك سكر الدم: الـCSF أقل من 2.2 mmol/L (40 mg/dL) = واطي
- Lymphocytes لحالها ما تعني viral. Lymphocytes + glucose واطي + أسابيع = TB
- تشنج أو confusion أو سلوك غريب = encephalitis → acyclovir فورًا → HSV PCR + MRI (temporal lobe)
- العلاج المبدئي ceftriaxone + vancomycin + dexamethasone
- نضيف ampicillin لو فوق 50 سنة أو حامل (Listeria)
| العلامة | كيف |
| Brudzinski | نثني الرقبة → الركب تنثني |
| Kernig | الورك 90° ونمد الركبة → ألم |
- 🔁 لو الـprotein طبيعي والبداية encephalitis → HSV مو TB

| النوع | المفتاح |
| Alzheimer | ينسى الجديد أول والشخصية سليمة. العلاج donepezil |
| Frontotemporal (behavioural) | الشخصية والتصرفات أول، أقل من 65 → frontal atrophy |

- الأمراض الثانية بالقصة (HIV، DM) طُعم: طريقة النزول هي اللي تقرر
- 🔁 تغير الشخصية بدري → FTD مو Alzheimer

== Nerves, MS and the cord
q: **2 weeks after gastroenteritis**: ascending weakness, areflexia | Guillain-Barré @SWR-0855
q: Numbness, MRI **periventricular** white matter lesions: supports diagnosis | CSF oligoclonal bands @SWR-0576
q: Known **cancer** + urine retention + **T10** sensory level | Dexamethasone @SWR-0796
idea:
## GBS
- بعد إسهال (Campylobacter) أو زكام بـ1–3 أسابيع + ضعف يطلع لفوق + areflexia
- الـCSF فيه protein عالي + خلايا طبيعية = albuminocytologic dissociation
- راقبي FVC (التنفس) → IVIG أو plasmapheresis (لا steroids)
- 🔁 لو الـreflexes موجودة والتعب يزيد مع الاستخدام → myasthenia
## MS
- بنت شابة + optic neuritis أو تنميل أو ضعف، يروح ويرجع
- أفضل فحص → MRI
- لو سأل وش يدعم التشخيص → CSF oligoclonal bands
- علاج الـrelapse → high-dose methylprednisolone
## Cord compression (سرطان)
- سرطان + ألم ظهر + ضعف رجول + sensory level + بول أو براز
- أول شي dexamethasone فورًا → MRI whole spine → radiotherapy أو surgery
- أشهر الأورام: lung، breast، prostate، myeloma
