@ 7 | Platelets A: اقرئي التحاليل بالترتيب
> h: الخطوات
> box: ١. شوفي الـplatelets :: واطية؟ طبيعية؟ ;; ٢. Platelets واطية :: PT/PTT طبيعي ← ITP. طويلة ← DIC ;; ٣. Platelets طبيعية :: PTT بس ← Hemophilia. PT + PTT ← Vitamin K ;; ٤. كله طبيعي :: Bleeding time طويل ← vWD. Clot lysis ← Factor XIII
> h: المواليد والأطفال
> list: ★ PT + aPTT طويل + platelets طبيعية ← Vitamin K deficiency (رضاعة طبيعية، أم على phenytoin) ;; ★ aPTT بس ← Hemophilia (ثلث الحالات بدون تاريخ عائلي) ;; ★ كله طبيعي + سرة تتأخر + نزيف ← Factor XIII ;; ★ Platelets 6–18 + الأم طبيعية ← Neonatal alloimmune ← Platelets + IVIG ;; ★ Platelets واطية + الأم SLE وplatelets الأم واطية ← Maternal autoantibodies ;; ★ aPTT ما يتصحح بالـmixing ← Acquired hemophilia
> h: الوراثة
> two: الأم نفسها مصابة :: vWD (autosomal dominant) ;; خاله (أخو أمه) :: Hemophilia (X-linked)
> h: نزيف بعد الختان
> list: ★ أول شي دايمًا ← Pressure dressing ;; بعدين نشوف السبب ;; ★ PT و aPTT طويلة جدًا + ما فيه factor بالخيارات ← Blood transfusion
> h: نقل الدم: ردود الفعل
> list: TACO ← ضيق + ضغط عالي (سوائل كثير) ;; ★ TRALI ← ضيق + ضغط واطي ;; ★ Hemolytic (AHTR) ← حرارة + ألم مكان الإبرة + Hb ينزل ;; Febrile ← حرارة ورجفة بس ;; ★ Allergic ← طفح واحمرار ← الوقاية: antihistamine ;; ★ أول شي بأي رد فعل ← Stop transfusion
> h: Warfarin والأعشاب
> list: ★ INR عالي بعد أعشاب ← وقفي الأعشاب وأعيدي INR ;; لو خلص مدة العلاج (DVT 3 شهور) ممكن نوقف warfarin
> sum: يعني باختصار: الختان = ضغط أول. TRALI = ضغط واطي. TACO = ضغط عالي. أي رد فعل = وقفي الدم.

@ 8 | Platelets B: HIT و DVT و PE و APS
> h: HIT
> two: Type 1 :: خفيف (أكثر من 100) أول 4 أيام، بدون جلطة ← راقبي ;; Type 2 :: أقل من 100 بعد اليوم 4 + جلطة ← Stop heparin + argatroban
> list: ★ ما أخذ heparin أبدًا ← مو HIT (فكري TTP) ;; ★ Platelets 16 + رجل باردة ← Stop UFH ;; ★ Platelets 18 + DVT ← Argatroban ;; ★ Platelets 59 + aPTT طويل ← Stop heparin + lepirudin ;; لا platelets، لا LMWH، لا protamine
> h: DVT و PE: العلاج
> box: Massive PE (ضغط واطي) :: tPA. لو stroke قريب ← IVC filter ;; مستقر :: DOAC لحاله ;; بعد عملية كبيرة :: LMWH (enoxaparin) ;; ما نقدر نميع :: IVC filter
> list: ★ CrCl أقل من 30 ← UFH ;; CrCl أكثر من 30 + BMI 40 أو أكثر ← LMWH 40 مرتين ;; ★ Stroke قبل شهرين ← IVC filter
> h: كم مدة؟
> list: ★ Unprovoked proximal ← طول العمر ;; Unprovoked distal ← حسب الحالة ;; Provoked ← 3–6 شهور ;; متكرر ← طول العمر
> h: Antiphospholipid syndrome
> list: ★ جلطات + إجهاض متكرر + livedo reticularis ← APS (ANA ممكن سلبي) ;; ★ على apixaban وطلع APS ← Warfarin ;; ★ Lupus anticoagulant positive ← اطلبي antiphospholipid antibodies كاملة
> h: أشياء ثانية
> list: ★ Hemophilia A ← Factor VIII ;; ★ مولود بعد vacuum + تورم يتعدى الـsutures + shock ← Subgaleal ← Blood transfusion + سوائل ;; ★ مسافر عادي ← تحرك وتمارين (بدون دواء)
> sum: يعني باختصار: HIT = وقفي heparin ثم argatroban. CrCl أقل من 30 = UFH. APS = warfarin.
