@ 9 | WBC: Immunodeficiency و Leukemia و الغدد
> h: B cell ولا T cell؟
> two: B cell بس (Bruton XLA) :: Infections جيوب ورئة + إسهال giardia + T cells طبيعية + Ig ما تنقاس + B cells قليلة ← IVIG ;; T + B (SCID) :: نفس الشي + فطريات وفيروسات ← Bone marrow transplant
> note: "X-linked" ما تعني شي لحالها. شوفي الكلمة اللي بعدها: agammaglobulinemia = IVIG. SCID = transplant.
> h: المتلازمات
> list: ★ Wiskott-Aldrich ← infections + إكزيما + platelets صغيرة وواطية، الطفح ما يجي على منطقة الحفاض ;; DiGeorge ← قلب + calcium واطي + ما فيه thymus (22q11) ;; CGD ← خراجات من catalase-positive (Staph، Aspergillus) ← NBT/DHR ;; ★ infections متكررة + إسهال ← Serum immunoglobulins
> h: Leukemia ولا Lymphoma؟
> two: Leukemia :: شحوب وأنيميا بدري + ألم عظام ← Bone marrow ;; Lymphoma :: غدد كبيرة + حرارة + نقص وزن ← Lymph node biopsy
> note: كلمة "confirm" بالسؤال ← Bone marrow. "Next" أو "initial" بدونها ← CBC / blood film.
> h: خط واحد ولا خطين؟
> list: ★ Platelets بس ← ITP ← CBC + film ;; ★ خطين ← Bone marrow ;; ★ خطين + retics عالية + bilirubin عالي + Coombs + ← Evans syndrome ;; ALL ← retics واطية ;; ★ أشهر leukemia بالأطفال ← ALL ← chemotherapy ;; ★ ALL بالـCSF ← Intrathecal chemo
> h: الغدد اللمفاوية
> list: ★ متحركة + ما تؤلم + أقل من 2 سم + الطفل بخير ← طمنيهم وراقبي 4–6 أسابيع ;; ★ مع حرارة + نقص وزن + كبد كبير ← Lymph node biopsy ;; ثابتة (fixed) ← biopsy
> sum: يعني باختصار: Bruton = IVIG. SCID = transplant. Confirm = bone marrow. Evans = Coombs + retics عالية.

@ 10 | Nephrology: الصوديوم والأملاح والـRTA
> h: Hyponatremia: كم أسرع؟
> box: Acute (أقل من 48 ساعة، بعد العمليات والسوائل) :: 3% saline دايمًا ;; Chronic + confusion أو صداع :: Fluid restriction ;; Chronic + تشنج أو coma :: 3% saline
> list: Normal saline ممكن يسوء SIADH ;; ★ بعد عملية + D5W + confusion ← المصدر ما حسمها (fluid restriction ولا 3%)
> h: الأملاح والـECG
> list: ★ Hypercalcemia ← QT قصير (سرطان بالعظم) ;; Hypocalcemia ← QT طويل (3 hypos: K، Mg، Ca) ;; Hyperkalemia ← peaked T ثم QRS عريض ثم sine wave ;; Hypokalemia ← T مسطحة و U waves ;; ★ Calcium عالي شوي + أعراض ← IV saline أول
> h: RTA
> list: ★ Type 1 (distal) ← K واطي + urine pH أكثر من 5.5 رغم acidosis. Sjögren و SLE ;; Type 2 (proximal) ← K واطي + Fanconi (سكر وفوسفات بالبول) ;; ★ Type 4 ← K عالي. Diabetic nephropathy
> h: Secondary hypertension
> list: Renin ↑ + aldosterone ↑ ← Renal artery stenosis (bruit) ;; Renin ↓ + aldosterone ↑ ← Conn ;; ★ Renin ↓ + aldosterone ↓ ← Liddle ;; ★ Bruit بالجنب ← CT (confirm). Doppler للفرز ;; ★ ما انضبط على CCB + ACE-I/ARB ← Diuretic ;; لا ACE-I مع ARB
> sum: يعني باختصار: QT قصير = Ca عالي. RTA 4 = K عالي. Renin و aldosterone واطيين = Liddle.

@ 11 | Nephrology: AKI و GN و CKD
> h: AKI
> list: ★ ترجيع وإسهال + ACE-I + كرياتينين 60 ← 160 ← Pre-renal ;; لو طال ← ATN ;; ★ بعد amoxicillin بأيام لأسابيع + eosinophils ← Acute interstitial nephritis ;; ★ Myeloma (plasma cells 10% أو أكثر + ألم ظهر) ← light chains ;; حجم الكلى: صغيرة ← ضغط. كبيرة ← polycystic. طبيعية ← سكري
> h: Nephrotic ولا Nephritic؟
> two: Nephrotic :: بروتين أكثر من 3.5 g + تورم حول العين + بدون دم + ضغط طبيعي ;; Nephritic :: دم + ضغط + بروتين أقل
> h: IgA ولا PSGN؟ (الوقت)
> two: 1–3 أيام بعد الحلق :: IgA nephropathy ;; 1–4 أسابيع بعد الحلق أو impetigo :: PSGN
> list: ★ طفح purpura + ألم بطن بعد زكام بيومين ← IgA vasculitis (HSP)، ولو مو موجود ← IgA nephropathy ;; ★ تأكيد PSGN ← Throat culture أو ASO ;; ★ C3 يرجع بعد 3–4 أسابيع (أو 6–8 حسب Nelson)
> h: CKD
> list: Stage 1 أكثر من 90، 2: 60–90، 3: 30–60، ★ 4: 15–30، 5: أقل من 15 ;; ★ ألم عظام + PTH عالي ← Phosphate عالي و calcium واطي ;; خطر gout يزيد
> h: متى dialysis؟
> list: أعراض uremia أو GFR أقل من 5 ;; ★ 3 U: Uremia (ترجيع، حكة)، Uremic pericarditis، Uremic encephalopathy أو neuropathy ← dialysis مباشرة ;; EFA: Electrolytes، Fluid، Acidosis لو ما استجابت للعلاج ;; ★ Pericardial effusion + ضغط واطي ← Pericardiocentesis أول ;; ★ Polycystic + eGFR ينزل بسرعة ← Prepare for transplant
> sum: يعني باختصار: حلق قبل أيام = IgA، قبل أسابيع = PSGN. Uremic neuropathy = dialysis.
