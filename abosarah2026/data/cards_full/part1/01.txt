@ 1 | Anemia: كيف أعرف النوع؟ (Microcytic)
> p: أول سؤال بأي أنيميا: الـMCV صغير ولا طبيعي ولا كبير؟ والـretics عالية (الجسم يكسر الدم) ولا واطية (ما يصنع)؟
> h: Iron deficiency anemia
> list: ★ طفل يشرب حليب بقر كثير + بسكويت + ما ياكل لحم ← IDA ;; ★ ياكل تراب أو طباشير (pica) + microcytic + ferritin واطي ← Pica مع IDA ;; ★ أدق تحليل وتأكيد واحد ← Low ferritin ;; RDW عالي + platelets عالية ;; ★ العلاج ← Oral iron + تعديل الأكل ;; ★ رضيع ما زال حديده ناقص رغم الأكل ← Iron supplements
> h: Thalassemia
> list: ★ شحوب من الصغر + طحال كبير + MCV واطي + RBC طبيعي أو عالي + target cells ← Beta thalassemia ;; ★ رضيع + nucleated RBCs + target cells + كبد وطحال ← Beta thalassemia major ;; ★ Frontal bossing + عظم الفك كبير ← اطلبي Hemoglobin (electrophoresis) ;; ★ مولود مات بـhydrops fetalis ← Alpha thalassemia ;; RDW طبيعي يفرقها عن IDA
> h: Lead poisoning
> list: ★ Basophilic stippling + target cells ← Lead ;; ★ Pica + فقر + مستواه بالمدرسة نازل + dense metaphyseal bands بالأشعة ← Blood lead level ;; ★ العلاج (من خيارات السؤال) ← D-penicillamine. ○ الشديد ← Succimer أو EDTA
> h: CKD وأنيميا
> list: ★ CKD stage 2 + تعب وشحوب ← Serum iron studies أول ;; ★ أدق تشخيص للسبب ← Bone marrow (بس قليل نحتاجه)
> sum: يعني باختصار: حليب بقر = IDA = ferritin. Target cells + RDW طبيعي = thalassemia. Stippling = lead.

@ 2 | Anemia: Hemolysis و Sickle cell و G6PD
> h: علامات الـhemolysis
> list: Retics عالية + haptoglobin واطي + LDH عالي + indirect bilirubin عالي ;; ★ مريض SLE + هالنمط ← Hemolytic anemia
> h: أي نوع hemolysis؟
> list: ★ Direct + indirect Coombs positive ← AIHA ;; ★ بدون صفار وبدون أدوية أو عدوى ← AIHA ;; ★ نفس التحاليل + صفار + حصى مرارة ← Hereditary spherocytosis ;; ★ مولود صفار أول 12 ساعة + smear spherocytes ← Osmotic fragility test ;; ★ تعب بعد الأكل + صفار + indirect bilirubin (فول أو أدوية) ← G6PD deficiency
> h: Mycoplasma والأدوية
> list: ★ اليوم 3 من الـantibiotic + hemolysis ← Drug-induced ← Stop antibiotics ;; بعد أسابيع من Mycoplasma ← Cold agglutinins ;; ★ Platelets نزلت بعد ceftriaxone ← Ceftriaxone
> h: Sickle cell disease
> list: ★ رضيع 6–18 شهر + dactylitis (تورم الأصابع) أو أنيميا + retics عالية ← Hb electrophoresis ;; ★ Electrophoresis: المرض ما فيه HbA ;; ★ Acute chest syndrome (حرارة + hypoxia + infiltrate جديد) ← Exchange transfusion + antibiotics ;; ★ حصى مرارة ← Chronic hemolysis
> h: الاستشارة الوراثية
> list: ★ زوجين أقارب وأخت الزوج عندها SCD ← Genetic counseling قبل الحمل ;; ★ الأب trait والأم ما فيها تاريخ ← خطر بسيط، وصفر لو الأم طلعت سلبية
> h: Splenectomy
> list: ★ يشفي: Spherocytosis ;; ★ "most commonly cured": ITP (حسب المصدر)
> sum: يعني باختصار: Coombs + = AIHA. صفار + حصى = spherocytosis. Dactylitis = electrophoresis.
