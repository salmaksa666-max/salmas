@ 35,36,37 | Acute ischemia: mesentery, limb, Buerger
> idea: ألم "أكبر من الفحص" أو طرف بارد مفاجئ ← فكري بـembolus (خصوصًا مع AF).
> flow Mesenteric ischemia: ★ AF/IHD + severe pain out of proportion :: Suspect mesenteric ischemia ;; ★ Initial :: CT angiography (مو plain X-ray) ;; ★ Gold standard / definitive :: Mesenteric angiography ;; ○ بعدها :: Resuscitation + heparin + revascularization
> flow Acute limb ischemia: ★ Pain + paralysis + paresthesia + pulseless :: Threatened limb ← Vascular surgeon ;; ★ AF + sudden leg pain + paralysis :: Embolectomy بدون imaging ;; ★ "Most appropriate diagnostic" :: CT angiography. "Next step" ← Heparin
> flow Buerger: ★ Young smoker + superficial thrombophlebitis + toe ulcers :: Buerger disease ← Stop smoking
> trick: ★ Amylase مرتفع قليلًا (أقل من ×٣) مع pain out of proportion ← Ischemia مو pancreatitis.
> trick: ★ Rest pain بدون بداية مفاجئة = chronic critical ischemia، البداية الحادة هي اللي تخليه ALI.
> trick: ★ Buerger ← Stop smoking، مو anticoagulation.

@ 38,39 | Leg & foot ulcers, Marjolin, diabetic foot
> idea: الموقع والـpulses يفرّقون: medial leg = venous، toes/malleolus + pulses ضعيفة = arterial، الكعب/القدم عند السكر = neuropathic.
> flow Ulcers: ★ Medial leg ulcer :: Venous hypertension ;; ★ Lateral malleolus / toe + pulses غايبة :: Atherosclerosis ;; ★ Diabetic foot + pulses موجودة :: Neuropathic ;; ★ Burn scar + ulcer ما يشفى :: Marjolin ← Biopsy (SCC)
> flow Diabetic foot: ★ Foul-smelling / necrotic :: Debridement أول (NPWT بعدين) ;; ★ Ulcer فوق first metatarsal + discharge :: MRI / CT for osteomyelitis ;; ★ Calf swelling + warmth + pulses intact :: Duplex ultrasound
> trick: ★ "MR angiography" دراسة أوعية مو MRI اللي يشخص osteomyelitis.
> trick: ★ Foot مو leg: ulcer عند السكر مع pulses = neuropathic.

@ 40,41 | Carotid disease, aortic dissection, AAA
> idea: Carotid: "symptomatic" معناه صار له TIA/stroke بنفس الجهة. والـaorta: وين الألم وشكل الـchest X-ray.
> flow Carotid: ★ TIA قديم + stenosis ٧٠–٩٠% :: Symptomatic ← Carotid endarterectomy ;; ★ "Now asymptomatic" :: ما يغيّر، يظل symptomatic ;; ★ TIA عابر + ECG طبيعي :: Carotid Doppler
> flow Aorta: ★ Epigastric/back pain + widened mediastinum :: Aortic dissection ;; ★ Epigastric pain فوق السرة عند كبير + enzymes طبيعية :: فكري aortic imaging (US ثم CT angio)
> trick: ★ Symptomatic = TIA أو stroke بنفس الـterritory، حتى لو الحين زين.
> trick: ★ Epigastric pain للظهر يخليك تفكرين pancreatitis، لكن widened mediastinum = aortic.
> trick: ★ "Male + smoker + 65" ← AAA screening ultrasound.

@ 42,43,44 | Thyroid & neck masses

> trick: ★ Thyroglossal يتحرك مع tongue protrusion. Thyroid nodule يتحرك بالبلع بس.

> trick: ★ Alkali يسوي deep necrosis حتى لو الفم شكله بسيط.
