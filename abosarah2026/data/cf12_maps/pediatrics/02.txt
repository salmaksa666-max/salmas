@ 176,177,178,179 | Pediatric hematology & immunology
> idea: CBC + MCV + RDW + Coombs يحددون.
> flow Anemia: ★ MCV 68 + RDW 20 + Platelets 490 :: Iron deficiency ;; ★ حليب بقر + بسكوت + low ferritin :: Iron deficiency ;; ★ Pica (soil, chalk) + microcytic + low ferritin :: Iron deficiency (مو lead) ;; ★ Direct + indirect Coombs + low Hb + high retics :: Autoimmune hemolytic anemia
> flow Others: ★ أكثر leukemia بالأطفال :: Acute lymphoblastic (ALL) ;; ★ ولد + low all Ig + few B cells + normal T cells :: X-linked agammaglobulinemia (Bruton)
> trick: ★ High RDW + high platelets مع microcytic = iron deficiency. Normal RDW + high RBC = thalassemia trait.
> trick: ★ Spherocytes في HS وAIHA، فالـCoombs يفرق.
> trick: ★ Low Ig مع normal B cells = CVID.

@ 180,181 | CKD staging & UTI

> flow Rules: ★ GFR ٢٨ :: CKD stage 4 (١٥–٢٩) ;; ★ ٢ شهر + fever + vomiting + lethargy + nitrites/leukocytes :: Send to hospital + IV antibiotics ;; ★ ٥ سنوات + fever + dysuria :: Oral antibiotics (amoxicillin حسب المفتاح)

@ 182,183 | Seizures & meningitis in children
> idea: Seizure: النوع من الأعراض. Meningitis: CSF.
> flow Seizures: ★ مراهقة + سقوط + weakness بالرجل + فقدت وعي ثم رجعت :: Atonic seizure ;; ★ Simple febrile seizure :: ٢٪ risk epilepsy ;; ★ Seizure بالنوم + وجه + طفل طبيعي + spikes :: Rolandic epilepsy
> flow Meningitis: ★ Meningitis + CSF lymphocytes + glucose طبيعي :: Viral ← IV acyclovir ;; ★ Fever + drowsiness + confusion + seizure :: LP ضروري
> trick: ★ Lymphocytes + LOW glucose = TB / fungal، مو viral.
> trick: ★ Febrile seizure مع recovery كامل ما يحتاج LP. Drowsiness وconfusion مستمرين = LP.
> trick: ★ Brief jerks عند الاستيقاظ = myoclonic (JME)، مو atonic.

@ 184,185,186,187,188,189 | Pediatric infections: TB, measles, varicella, HFMD, scarlet fever, bites
> idea: كل عدوى clue كلاسيكي. وTB contacts: positive test = latent TB.
> flow Clues: ★ Contact مع TB + test positive (PPD ١٤ مم) + asymptomatic :: Treat latent TB ;; ★ طفل < ٥ سنوات + contact open TB + BCG :: IGRA + INH (BCG ما يغني) ;; ★ Koplik spots + maculopapular rash :: Measles ← Airborne ;; ★ Vesicles بمراحل مختلفة + non-vaccinated :: Varicella ;; ★ Rash يد وقدم + oral ulcers + daycare :: HFMD ← Fecal-oral ;; ★ Sandpaper rash + strawberry tongue + pharyngitis :: Streptococcus pyogenes ;; ★ Bat bite :: Rabies vaccine + immunoglobulins
> trick: ★ Measles وvaricella وTB = airborne (N95 / negative pressure).
> trick: ★ Bats دايم category III حتى لو العضة بسيطة.
> trick: ★ Strawberry tongue + حمى طويلة + conjunctivitis + يد منتفخة = Kawasaki.
> trick: ★ Vesicles كلها نفس المرحلة = smallpox.
